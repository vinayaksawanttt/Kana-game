#### Section A: Pattern Construction (練習A)
- 1. これ / 名刺 (This is a business card) => これは名刺です。
- 2. それ / ボールペン・シャープペンシル (Alternative question) => それはボールペンですか、シャープペンシルですか。

- 4. あれ / 佐藤さんのかばん (Ms. Sato's bag) => あれは佐藤さんのかばんです。
- 5. あれ / だれの (Whose is that over there?) => あれはだれのですか。
- 6. このかぎ / わたしの (This key is mine) => このかぎはわたしのです。
