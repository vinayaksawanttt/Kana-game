## Lesson 1: お願いがあるんですが (Polite Requests, Resemblance & Clauses)

### Part I: 文法・練習 1 (〜ていただけないでしょうか — Polite Requests) [Grammar 1]

#### Section A: Situational Requests
- 1. 日本語でレポートを書いたが、間違いがないかどうか心配だ（先生に） => 先生、日本語でレポートを書いたんですが、間違いがないかどうか見ていただけないでしょうか。
- 2. 日本人のうちに招待されたが、どんなお土産がいいかわからない（先輩に） => 先輩、日本人のうちに招待されたんですが、どんなお土産がいいか教えていただけないでしょうか。
- 3. しばらく留守にするので、荷物が届いたら預かってもらいたい（管理人に） => すみません、しばらく留守にするんですが、荷物が届いたら預かっていただけないでしょうか。

### Part II: 文法・練習 2 (〜のようだ・〜のような・〜のように) [Grammar 2]

#### Section A: Describing Similes
- 1. ワットさんの家の庭・広い => ワットさんの家の庭は広くて、まるで公園のようです。
- 2. あの女の子・かわいい => あの女の子はかわいくて、まるで人形のようです。
- 3. 山の上から見た景色・きれい => 山の上から見た景色はきれいで、まるで絵のようです。

#### Section B: Question & Answer with 〜のような
- 1. どんな町に住みたいですか。 => 奈良のような歴史のある町に住みたいです。
- 2. どんな人と友達になりたいですか。 => 太陽のような明るい人と友達になりたいです。
- 3. どんな映画が好きですか。 => ジブリのような夢のある映画が好きです。

### Part III: 文法・練習 4 & 5 (〜を〜と言う・〜という〜) [Grammar 4]

#### Section A: Naming & Identifying
- 1. 座るとき使う小さい布団・座布団 => 座るとき使う小さい布団を座布団と言います。
- 2. 畳や床の上にきちんと座ること・正座 => 畳や床の上にきちんと座ることを正座と言います。
- 3. あいさつのとき、頭を下げること・おじぎ => あいさつのとき、頭を下げることをおじぎと言います。
- 4. 今年の忘年会はどこでするんですか。（「かめや」） => 「かめや」という店でするんです。
- 5. 図書館で何か本を借りましたか。（『畳の文化』） => ええ、『畳の文化』という本を借りました。
- 6. 風邪ですか。薬を買ってきましょうか。（「ネットール」） => ええ、「ネットール」という薬を買ってきてください。

### Part IV: 問題 Review & Paragraph Cloze (Lesson 1) [Grammar 6]

#### Section A: Particle & Form Selection (〜ような / 〜ように / WH〜ても)
- 1. あなたの国に相撲の（ような / ように）スポーツがありますか。 => ような
- 2. 先週買ったパンが石の（ような / ように）硬くなってしまった。 => ように
- 3. 新しい家の居間には、この写真の（ような / ように）テーブルが合うと思います。 => ような
- 4. 母が亡くなってからは、姉がわたしたちの世話をしてくれて、まるで母親の（よう / ような）でした。 => よう
- 5. ディズニーランドは（だれ）と（行って）も、楽しいところです。 => だれ・行っても
- 6. 最近、（何）を（やって）も、うまくいかない。 => 何・やっても
- 7. 彼の名前は長くて、（何回）（聞いて）も、覚えられない。 => 何回・聞いても
- 8. パワー電気のコンピューターは（どこ）で（買って）も同じ値段です。 => どこ・買っても
- 9. 彼の部屋は（いつ）（行って）も、きちんと片づいている。 => いつ・行っても
- 10. （どんなに）（急いで）も、9時の新幹線には間に合わないだろう。 => どんなに・急いでも

#### Section B: 茶道 Paragraph Cloze [Grammar 6]
- 1. 茶道ではお茶をいれることを「お茶をたたてる」と言います。伝統的な方法でお茶をたてて飲む人は（非常に / ふだん / 最も）少なくなっています。 => 非常に
- 2. しかし、お茶は健康にいいので、いろいろなお菓子や飲み物に使われて、（非常に / ふだん / 最も）の生活の中でお茶の味を楽しむ人が増えています。 => ふだん

## Lesson 2: 何のことですか (〜たら、〜という〜、〜ように、〜みたい)

### Part I: 文法・練習 1 & 2 (〜たら、〜た / 〜というのは〜のことだ) [Grammar 1]

#### Section A: Conditional Discovery & Definitions
- 1. ゆっくり休む・元気になる => ゆっくり休んだら、元気になった。
- 2. 毎日水をやる・きれいな花が咲く => 毎日水をやったら、きれいな花が咲いた。
- 3. 久しぶりにテニスをする・とても疲れる => 久しぶりにテニスをしたら、とても疲れた。
- 4. メール・郵便（Eメール） => 今おっしゃったメールというのは郵便ということですか。 ……いいえ、Eメールのことです。
- 5. プレイガイド・遊び方を教える（チケットを売っているところ） => 今おっしゃったプレイガイドというのは遊び方を教えるということですか。 ……いいえ、チケットを売っているところのことです。
- 6. ダイエット・栄養に気をつける（やせるためにカロリーが高い物を食べない） => 今おっしゃったダイエットというのは栄養に気をつけるということですか。 ……いいえ、やせるためにカロリーが高い物を食べないということです。

### Part II: 文法・練習 3, 4 & 5 (…という〜 / …ように言う / 〜みたいだ) [Grammar 3]

#### Section A: Reported Clauses & Indirect Commands
- 1. 意見がありました・無駄なコピーはやめたほうがいいです => どんな意見があったんですか。 ……無駄なコピーはやめたほうがいいという意見がありました。
- 2. 医者にアドバイスをもらいました・しばらく仕事を休んだほうがいいです => 医者にどんなアドバイスをもらったんですか。 ……しばらく仕事を休んだほうがいいというアドバイスをもらいました。
- 3. 最近、事件が多いです・歩いている女性がバッグを奪われます => 最近、どんな事件が多いんですか。 ……歩いている女性がバッグを奪われるという事件が多いんです。
- 4. 妻・頼む（「ケーキを買ってきて」） => わたしは妻にケーキを買ってくるように頼まれました。
- 5. 医者・言う（「お酒をやめたほうがいいですよ」） => わたしは医者にお酒をやめたほうがいいと言われました。
- 6. 母・注意する（「早くうちへ帰りなさい」） => わたしは母に早くうちへ帰るように注意されました。

#### Section B: Similes with 〜みたいだ / みたいな
- 1. 車（箱・四角い） => 今どんな車が売れているんですか。 ……箱みたいに四角い車が売れています。
- 2. カメラ（名刺・小さい） => 今どんなカメラが売れているんですか。 ……名刺みたいに小さいカメラが売れています。
- 3. 携帯電話（時計・腕につけられる） => 今どんな携帯電話が売れているんですか。 ……時計みたいに腕につけられる携帯電話が売れています。

### Part III: 問題 Review & Paragraph Cloze (Lesson 2) [Grammar 5]

#### Section A: 彼女とけんか Paragraph Cloze [Grammar 5]
- 1. 料理の作り方が、彼女とのあいだでちょっと違ったのだ。（それで / それに）、けんかになってしまった。 => それで
- 2. 1週間が過ぎたが、彼女とは（いまさら / いまだに）話をしていない。 => いまだに
- 3. （今にも / いまさら）自分から謝るのも嫌だ。 => いまさら
- 4. （それに / しかし）、こんなことを続けているのはよくないと思う。 => しかし
- 5. 早く彼女と（普通に / まるで）話せるようになりたい。 => 普通に

## Lesson 3: 遅れそうなんです (Permission, Decisions & Appearances)

### Part I: 文法・練習 1, 2 & 3 (〜させていただけないでしょうか / ことにする / ことになる) [Grammar 1]

#### Section A: Seeking Permission & Making Decisions
- 1. 授業を見学したい（日本語学校の受付の人に） => あのう、授業を見学させていただきたいんですが、見学させていただけないでしょうか。
- 2. 休みをとりたい（アルバイト先の店長に） => 店長、用事があるので、休みをとらせていただけないでしょうか。
- 3. この研修を受けたい（部長に） => 部長、勉強のために、ぜひこの研修を受けさせていただけないでしょうか。
- 4. 日本語が上手になるように（〜ことにしている） => 日本語が上手になるように、毎日日本語の本を読むことにしています。
- 5. ごみを減らすために（〜ことにしている） => ごみを減らすために、買い物のとき袋を持って行くことにしています。
- 6. だれがこの仕事を担当しますか。（鈴木さん） => 鈴木さんが担当することになりました。
- 7. いつ結婚するんですか。（今年の秋） => 今年の秋に結婚することになりました。
- 8. 旅行はどこへ行くんですか。（東北の温泉） => 東北の温泉へ行くことになりました。

### Part II: 文法・練習 4 & 5 (〜てほしい / 〜そう) [Grammar 4]

#### Section A: Wishes & Visual Appearances
- 1. ハンス君が来週サッカーの試合に出るそうだよ。 => ぜひ勝ってほしいね。
- 2. もう3月も終わりなのに、いつまでも寒いですね。 => 早く暖かくなってほしいですね。
- 3. 駅の前に自転車がたくさん置いてあって、通れないね。 => もっときれいに並べてほしいね。
- 4. 山田さん・かばん => 山田さんは重そうなかばんを持っています。
- 5. マリアさん・服 => マリアさんは暖かそうな服を着ています。
- 6. ミラーさん・しゃべる => ミラーさんは楽しそうにしゃべっています。
- 7. ワットさん・食べる => ワットさんはおいしそうに食べています。

### Part III: 問題 Review & Paragraph Cloze (Lesson 3) [Grammar 5]

#### Section A: 3月28日（火）晴れ Paragraph Cloze [Grammar 5]
- 1. 天気はよかったが、桜はまだ咲いていなかった。（やはり / これまでの / できれば / わざわざ）花見にはちょっと早すぎたようだ。 => やはり
- 2. （やはり / これまでの / できれば / わざわざ）休みを取って行ったのに、残念だった。 => わざわざ
- 3. 来年また行こうと思っている。（やはり / これまでの / できれば / わざわざ）今度は彼女といっしょに行きたい。 => できれば

## Lesson 4: 伝言、お願いできますか (Hearsay, Causative-Passive & Third-Person Feelings)

### Part I: 文法・練習 1, 2 & 3 (…ということだ / …の？ / 〜ちゃう) [Grammar 1]

#### Section A: Formal Relay & Casual Contractions
- 1. 医者の説明・専門の病院で検査してもらったほうがいいです => 医者の説明では、専門の病院で検査してもらったほうがいいということです。
- 2. 部長の話・シュミットさんはあさって帰国されます => 部長の話では、シュミットさんはあさって帰国されるということです。
- 3. 『ノルウェイの森』、もう読んだ？（うん、きのう全部） => うん、きのう全部読んじゃった。
- 4. 晩ご飯、何か作っとこうか？（うん、カレー） => うん、カレー作っといて。
- 5. レストラン、込んでた？（ううん） => ううん、込んでなかった。

### Part II: 文法・練習 4, 5, 6 & 7 (〜させられる / 〜である / 〜がる) [Grammar 4]

#### Section A: Causative-Passive & Written Style
- 1. 声が変ですね。（課長・カラオケで歌う） => ええ、課長にカラオケで歌わされたんです。
- 2. 足が痛いんですか。（先輩・運動場を走る） => ええ、先輩に運動場を走らされたんです。
- 3. たばこを吸わないんですか。（妻・やめる） => ええ、妻にやめさせられたんです。
- 4. 姉・雷の音を聞くと、怖い => 姉は雷の音を聞くと、怖がります。
- 5. 弟・おふろに入るのが嫌だ => 弟はおふろに入るのを嫌がります。
- 6. うちの子ども・月曜日、学校へ行きたくない => うちの子どもは月曜日、学校へ行きたがります / 行きたがりません。

### Part III: 問題 Review & Paragraph Cloze (Lesson 4) [Grammar 4]

- 2. 急ぐ（使役受身） => 急がされる

#### Section B: 山田君からのはがき Paragraph Cloze [Grammar 8]

## Lesson 5: どう行ったらいいでしょうか (Anaphora, Advice, & Directions)

### Part I: 文法・練習 1 & 2 (あ〜・そ〜 / …んじゃない？) [Grammar 1]

#### Section A: Reference Words & Gentle Advice
- 1. 『美しい日本語』という教科書を持っていますか。（…いいえ、＿＿はどんな教科書ですか） => それ
- 2. 今年の忘年会は「かめや」にしませんか。（…ああ、先月できた居酒屋ですね。＿＿のやきとりはおいしいそうですね） => あそこ
- 3. タイから来たタワポンさんを知っていますか。（…いいえ、＿＿人、この大学で勉強しているんですか） => その
- 4. パワー電気の新しいパソコンを見ましたか。（…ええ、＿＿は画面がきれいで、見やすいですね） => あれ
- 5. 父は田舎の高校を出て、東京の大学に入った。＿＿で、初めて母に会った。 => そこ
- 6. 駅で男の人に道を聞かれたんだけど、＿＿人、有名な俳優にそっくりだったの。 => その
- 7. 留守番電話に伝言を入れたのに、彼は＿＿を聞かなかったそうです。 => それ
- 8. 課長は調子が悪そうですね。 => 病院へ行ったほうがいいんじゃないですか。
- 9. 最近カリナさんを見ませんね。 => 国へ帰ったんじゃないですか。

### Part II: 文法・練習 3, 4 & 6 (〜たところに / 〜ようとする / 〜との・での) [Grammar 3]

#### Section A: Directions, Attempt, & Noun Modification
- 1. 友達からもらったメールを読んだ（〜からの） => 友達からのメールを読んだ。
- 2. 東京まで行く切符は全部売り切れだった（〜までの） => 東京までの切符は全部売り切れだった。
- 3. 友達と行った旅行はとても楽しかった（〜との） => 友達との旅行はとても楽しかった。
- 4. IMCで受けた研修は役に立った（〜での） => IMCでの研修は役に立った。
- 5. 彼女にあげたプレゼントは5千円もした（〜への） => 彼女へのプレゼントは5千円もした。
- 6. 電車を（降りよう）としたら、ドアが閉まってしまった。 => 降りよう
- 7. いくら聞いても、息子はけんかの原因を（話そう）としません。 => 話そう
- 8. あの橋を（渡った）ところで、車を止めてください。 => 渡った

### Part III: 問題 Review & Paragraph Cloze (Lesson 5) [Grammar 7]

#### Section A: 起きられない Paragraph Cloze [Grammar 7]
- 1. 僕の時計が「7時だよ。おはよう。起きろ。」と、起こしてくれるのだが、（そこで / わざと / 無意識に / 自然に）止めて、また寝てしまう。 => 無意識に
- 2. （そこで / わざと / 無意識に / 自然に）、友達にいい方法がないか聞いてみた。 => そこで
- 3. ワンさんは、朝になると（無意識に / 自然に）目が覚めるそうだ。 => 自然に

## Lesson 6: 行かせていただきたいんですが (Quoting `って`, Plans, & 〜てくる/〜ていく)

### Part I: 文法・練習 2 & 3 (〜つもり / 〜てばかりいる) [Grammar 2]

#### Section A: Intentions, Advice, & Changing Direction
- 1. いつも肉を食べている人に => 肉ばかり食べているけど、もっと野菜も食べたほうがいいよ。
- 2. いつもほかの人のことを心配している人に => ほかの人のことばかり心配しているけど、自分のことも考えたほうがいいよ。
- 3. 子どもを褒めないで、いつもしっかている人に => 子どもをしかってばかりいないで、たまには褒めてあげたほうがいいよ。
- 4. 漢字が覚えられないんです。（〜とか〜） => 毎日少しずつ書くとか、好きな漫画を読むとかすればいいですよ。
- 5. 貯金がなかなか増えません。（〜とか〜） => 無駄な物を買わないとか、毎月決まった額を貯金するとかすればいいですよ。
- 6. 会社に（入って / 入った）ばかりのころは、（失敗して / 失敗した）ばかりいました。 => 入った・失敗して
- 7. （買って / 買った）ばかりの自転車が壊れてしまいました。 => 買った
- 8. 隣の部屋からだれか話しているのが聞こえて（くる / いく）。 => くる
- 9. さっきこの部屋に入って（きた / いった）けど、すぐ出て（きた / いった）よ。 => きた・いった
- 10. 最近になってやっと、家族の大切さがわかって（きた / いった）。 => きた

### Part II: 問題 Review & Paragraph Cloze (Lesson 6) [Grammar 5]

#### Section A: 七転び八起き Cloze [Grammar 5]

- 2. 皆さんの国にも（具体的な / 同じような）ことばがありますか。 => 同じような

## Lesson 7: 楽しみにしてます・遠慮させてください (Obligation, Causative & Conditionals)

### Part I: 文法・練習 1–6 (〜なくてはならない / 〜だけだ / 〜かな / 〜させる / 〜なら) [Grammar 1]

#### Section A: Rules, Minimal Action, & Causative Emotions
- 1. スピーチ大会に出なくてはなりませんか。（いいえ） => いいえ、出たくなかったら、出なくてもかまいませんよ。
- 2. あのレストランには、上着を着て行かなくてはいけませんか。（いいえ） => いいえ、きれいなシャツを着ていれば、着て行かなくてもかまいませんよ。
- 3. カリナさんの展覧会に行きたいんですが、招待状がなくてもかまいませんか。（はい） => はい、招待状がなくても、だれでも見られますよ。
- 4. 先生は冗談を言った・学生たちは笑った => 先生は冗談を言って、学生たちを笑わせた。
- 5. 僕たちは歌や踊りを見せた・お客さんは楽しんだ => 僕たちは歌や踊りを見せて、お客さんを楽しませた。
- 6. 転勤の話を断った・上司（〜させる） => 転勤の話を断って、上司を怒らせてしまいました。

## Lesson 12: ご迷惑をかけてすみませんでした (Practice & Review)

### Part I: 文法練習 (Lesson 12) [Grammar 1]

#### Section A: `…もの／もんだから` & Adversative Passive `〜（ら）れる`
- 1. アルバイトを辞めてしまいました・いろいろ事情がありました →（〜ものですから） => アルバイトを辞めてしまいました。…いろいろ事情があったものですから。
- 2. 上司に相談しませんでした・自分で解決できると思いました →（〜ものですから） => 上司に相談しませんでした。…自分で解決できると思ったものですから。
- 3. みんなが先に行った・道がわからなくなった →（受身で文を作る） => みんなに先に行かれて、道がわからなくなった。
- 4. アルバイトの学生が辞めた・作業が遅れた →（受身で文を作る） => アルバイトの学生に辞められて、作業が遅れた。
- 5. 留守のあいだに泥棒が入った・銀行のカードを盗まれた →（受身で文を作る） => 留守のあいだに泥棒に入られて、銀行のカードを盗まれた。
- 6. 昨日はよく眠れましたか。（隣の部屋の赤ちゃん） => いいえ、夜中に赤ちゃんに泣かれて、よく眠れませんでした。
- 7. レポートは書けましたか。（友達が遊びに来た） => いいえ、友達に来られて、レポートが書けませんでした。
- 8. 踊りはよく見えましたか。（背が高い人の後ろ） => いいえ、前の人に立たれて、踊りがよく見えませんでした。
- 9. 日が当たらなくなりました →（隣のビルの工事） => 隣に高いビルを建てられて、日が当たらなくなりました。
- 10. 話ができませんでした →（隣のグループ・大声で歌う） => 隣のグループに大声で騒がれて、話ができませんでした。
- 11. 車が出せません →（駐車場の前に駐車する） => 前に車を止められて、車が出せません。

### Part II: `〜たり〜たり`・`〜っぱなし`・`おかげで / せいで` [Grammar 3]

#### Section A: Textbook Completion & Transformation Drills
- 1. 道がわからなくて、同じ道を＿＿＿してしまいました。 => 行ったり来たり
- 2. 階段の蛍光灯が＿＿＿しています。新しいのに換えなければ。 => ついたり消えたり
- 3. 年を取ると、＿＿＿するのが大変です。 => 立ったり座ったり
- 4. 社員食堂の味はメニューによって、＿＿＿します。 => よかったり悪かったり（おいしかったりまずかったり）
- 5. （窓が開いたまま）気をつけなくちゃ → => 窓が開けっぱなしだよ。気をつけなくちゃ。
- 6. （水道が出たまま）もったいないね → => 水が出しっぱなしだよ。もったいないね。
- 7. （アイロンがついたまま）危ないね → => アイロンがつけっぱなしだよ。危ないね。
- 8. 仕事がうまくいきました →（理由をおかげでで） => 先輩がアドバイスしてくれたおかげで、仕事がうまくいきました。
- 9. 夕べはぐっすり眠れました →（理由をおかげでで） => 静かなホテルに泊まったおかげで、夕べはぐっすり眠れました。
- 10. 世界のニュースを見たり、聞いたりできます →（理由をおかげでで） => インターネットが普及したおかげで、世界のニュースを見たり聞いたりできます。
- 11. （ピアノの先生は厳しかった / ピアノが嫌いになった / ピアノが上手になった） => 先生のせいでピアノが嫌いになった。／でも、先生のおかげでピアノが上手になった。
- 12. （今朝の電車の事故は大変だった / 学校に遅刻した / テストが来週になった） => 電車の事故のせいで学校に遅刻した。／でも、事故のおかげでテストが来週になった。
- 13. 学校の成績が下がった →（せいで） => テレビばかり見ているせいで、学校の成績が下がった。
- 14. バスに乗り遅れた →（せいで） => 寝坊したせいで、バスに乗り遅れた。
- 15. 歯が悪くなった →（せいで） => 甘い物ばかり食べて歯を磨かなかったせいで、歯が悪くなった。
