# Genki II Practice Exercises (れんしゅう)

## Lesson 13: アルバイト探し (Looking for a Part-time Job)

### Part I: 一キロ泳げます [Grammar 1: Potential Verbs]

#### Section A: Change the verbs into the potential forms. [Track: K13-09]
- Example: 食べる → 食べられる
- 1. 話す => 話せる
- 2. する => できる
- 3. 行く => 行ける
- 4. 寝る => 寝られる
- 5. 来る => 来られる
- 6. 見る => 見られる
- 7. やめる => やめられる
- 8. 借りる => 借りられる
- 9. 飲む => 飲める
- 10. 待つ => 待てる
- 11. 泳ぐ => 泳げる
- 12. 働く => 働ける
- 13. 編む => 編める

#### Section B: Describe the things that Mary can do. [Track: K13-10]
- Example: 1 km → メアリーさんは 一キロ泳げます。
- 1. Japanese song => メアリーさんは 日本の歌が歌えます。
- 2. violin => メアリーさんは バイオリンが弾けます。
- 3. karate => メアリーさんは 空手ができます。
- 4. chopsticks => メアリーさんは はしが使えます。
- 5. Japanese cooking => メアリーさんは 日本の料理が作れます。
- 6. motorcycle => メアリーさんは バイクに乗れます。
- 7. car => メアリーさんは 車が運転できます。
- 8. sweater => メアリーさんは セーターが編めます。
- 9. many kanji => メアリーさんは 漢字がたくさん書けます。（読めます。）
- 10. early in the morning => メアリーさんは 朝早く起きられます。
- 11. hot bath => メアリーさんは 熱いお風呂に入れます。

#### Section C: Answer the questions using the potential verb in the negative. [Track: K13-11]
- Example: 着物を買いましたか。(too expensive) → いいえ、高すぎて買えませんでした。
- 1. スリランカのカレーを食べましたか。(too spicy) => いいえ、辛すぎて食べられませんでした。
- 2. 宿題をしましたか。(too difficult) => いいえ、難しすぎてできませんでした。
- 3. 温泉に入りましたか。(too hot) => いいえ、熱すぎて入れませんでした。
- 4. きのう出かけましたか。(too busy) => いいえ、忙しすぎて出かけられませんでした。
- 5. 漢字を全部覚えましたか。(too many) => いいえ、多すぎて覚えられませんでした。
- 6. 海で泳ぎましたか。(too cold) => いいえ、冷たすぎて泳げませんでした。

### Part II: 物価が高いし、人がたくさんいるし [Grammar 2: 〜し〜し]

#### Section A: Answer the questions using 〜し〜し. [Track: K13-12]
- Example: 日本に住みたいですか。(物価が高いです。人がたくさんいます。) → 物価が高いし、人がたくさんいるし、住みたくないです。
- 1. 今週は忙しいですか。(試験があります。宿題がたくさんあります。) => 試験があるし、宿題がたくさんあるし、忙しいです。
- 2. 新しいアパートはいいですか。(空港に近いです。便利です。) => 空港に近いし、便利だし、いいです。
- 3. 経済の授業を取りますか。(先生は厳しいです。長いレポートを書かなきゃいけません。) => 先生は厳しいし、長いレポートを書かなきゃいけないし、取りません。
- 4. 旅行は楽しかったですか。(食べ物がおいしくなかったです。言葉がわかりませんでした。) => 食べ物がおいしくなかったし、言葉がわからなかったし、楽しくなかったです。
- 5. 今晩、パーティーに行きますか。(ちょっと気分が悪いです。きのうもパーティーに行きました。) => ちょっと気分が悪いし、きのうもパーティーに行ったし、行きません。
- 6. 日本語の新聞が読めますか。(漢字が読めません。文法がわかりません。) => 漢字が読めないし、文法がわからないし、読めません。
- 7. 一人で旅行ができますか。(日本語が話せます。もう大人です。) => 日本語が話せるし、もう大人だし、できます。
- 8. 田中さんが好きですか。(うそをつきます。約束を守りません。) => うそをつくし、約束を守らないし、好きじゃないです。

### Part III: おいしそうです [Grammar 3: 〜そう (Looks like)]

#### Section A: Describe the following pictures using 〜そう. [Track: K13-13]
- Example: すし (delicious) → このすしはおいしそうです。
- 1. カレー (spicy) => このカレーは辛そうです。
- 2. ケーキ (sweet) => このケーキは甘そうです。
- 3. 家 (old) => この家は古そうです。
- 4. アパート (new) => このアパートは新しそうです。
- 5. マンション (convenient) => このマンションは便利そうです。
- 6. 先生 (strict) => この先生は厳しそうです。
- 7. 学生 (sleepy) => この学生は眠そうです。
- 8. おじいさん (energetic) => このおじいさんは元気そうです。
- 9. おばあさん (mean) => このおばあさんはいじわるそうです。
- 10. 子供 (sad) => この子供は悲しそうです。
- 11. 男の人 (lonely) => この男の人はさびしそうです。
- 12. 弁護士 (smart) => この弁護士は頭がよさそうです。
- 13. やくざ (scary) => このやくざは怖そうです。

### Part IV: 着てみます [Grammar 4: 〜てみる (Try doing)]

#### Section A: Respond to the following sentences using 〜てみる. [Track: K13-15]
- Example: この服はすてきですよ。 → じゃあ、着てみます。
- 1. 経済の授業はおもしろかったですよ。 => じゃあ、取ってみます。
- 2. あの映画を見て泣きました。 => じゃあ、見てみます。
- 3. この本は感動しました。 => じゃあ、読んでみます。
- 4. 豆腐は体にいいですよ。 => じゃあ、食べてみます。
- 5. 東京はおもしろかったですよ。 => じゃあ、行ってみます。
- 6. あの歌手の歌はいいですよ。 => じゃあ、聞いてみます。
- 7. このアプリは便利ですよ。 => じゃあ、使ってみます。

### Part V: 紅茶なら飲みました [Grammar 5: 〜なら]

#### Section A: Answer the questions using 〜なら. [Track: K13-16]
- Example: ロバートさんはけさ、コーヒーを飲みましたか。(○ tea × coffee) → 紅茶なら飲みましたが、コーヒーは飲みませんでした。
- 1. ロバートさんはバイクに乗れますか。(○ bicycle × motorbike) => 自転車なら乗れますが、バイクには乗れません。
- 2. ロバートさんはニュージーランドに行ったことがありますか。(○ Australia × New Zealand) => オーストラリアなら行ったことがありますが、ニュージーランドには行ったことがありません。
- 3. ロバートさんはゴルフをしますか。(○ soccer × golf) => サッカーならしますが、ゴルフはしません。
- 4. カルロスさんは日本の経済に興味がありますか。(○ history × economics) => 歴史なら興味がありますが、経済には興味がありません。
- 5. カルロスさんは彼女がいますか。(○ friend × girlfriend) => 友だちならいますが、彼女はいません。
- 6. カルロスさんは土曜日に出かけられますか。(○ Sunday × Saturday) => 日曜日なら出かけられますが、土曜日には出かけられません。

### Part VI: 一日に二回食べます [Grammar 6: Frequency]

#### Section A: Make sentences expressing frequency. [Track: K13-17]
- Example: twice a day (eat) → 一日に二回食べます。
- 1. three times a day (brush teeth) => 一日に三回歯をみがきます。
- 2. seven hours a day (sleep) => 一日に七時間寝ます。
- 3. three hours a day (study) => 一日に三時間勉強します。
- 4. once a week (clean) => 一週間に一回掃除します。
- 5. twice a week (laundry) => 一週間に二回洗濯します。
- 6. three days a week (part-time job) => 一週間に三日アルバイトをします。
- 7. five days a week (school) => 一週間に五日学校に行きます。
- 8. once a month (movie) => 一か月に一回映画を見ます。

## Lesson 14: バレンタインデー (Valentine's Day)

### Part I: チョコレートがほしいです [Grammar 1: ほしい / ほしがっている]

#### Section A: Say whether you want or do not want each item. [Track: K14-09]
- Example: チョコレート → チョコレートがほしいです。 / チョコレートがほしくないです。
- 1. マフラー => マフラーがほしいです。 / マフラーがほしくないです。
- 2. 口紅 (lipstick) => 口紅がほしいです。 / 口紅がほしくないです。
- 3. パソコン => パソコンがほしいです。 / パソコンがほしくないです。
- 4. お皿 => お皿がほしいです。 / お皿がほしくないです。
- 5. 自転車 => 自転車がほしいです。 / 自転車がほしくないです。

#### Section B: Say whether you wanted or did not want each item when you were a child. [Track: K14-10]
- Example: まんが → 子供の時、まんががほしかったです。 / ほしくなかったです。
- 1. 馬のおもちゃ (toy horse) => 子供の時、おもちゃがほしかったです。
- 2. 指輪 (ring) => 子供の時、指輪がほしくなかったです。
- 3. ぬいぐるみ (stuffed animal) => 子供の時、ぬいぐるみがほしかったです。
- 4. 花束 (flowers) => 子供の時、花がほしくなかったです。
- 5. セーター (sweater) => 子供の時、セーターがほしかったです。

### Part II: ギターが弾けるかもしれません [Grammar 2: 〜かもしれない]

#### Section A: Answer the questions about Takeshi using 〜かもしれません. [Track: K14-11]
- Example: たけしさんはギターが弾けますか。 → さあ……。弾けるかもしれません。でも、弾けないかもしれません。
- 1. あした忙しいですか。 => 忙しいかもしれません。でも、忙しくないかもしれません。
- 2. 料理が上手ですか。 => 上手かもしれません。でも、上手じゃないかもしれません。
- 3. けちですか。 => けちかもしれません。でも、けちじゃないかもしれません。
- 4. 政治に興味がありますか。 => 興味があるかもしれません。でも、興味がないかもしれません。
- 5. 空手ができますか。 => できるかもしれません。でも、できないかもしれません。
- 6. 英語が話せますか。 => 話せるかもしれません。でも、話せないかもしれません。
- 7. メアリーさんに指輪をあげましたか。 => あげたかもしれません。でも、あげなかったかもしれません。

### Part III: 友だちにチョコレートをあげました [Grammar 3: あげる / くれる / もらう]

#### Section A: Say what you will give to the following people. [Track: K14-12]
- Example: father (whiskey) → 父にお酒をあげます。
- 1. mother (lipstick) => 母に口紅をあげます。
- 2. friend (chocolate) => 友だちにチョコレートをあげます。
- 3. roommate (T-shirt) => ルームメイトにTシャツをあげます。
- 4. younger brother (watch) => 弟に時計をあげます。
- 5. teacher (black tea) => 先生に紅茶をあげます。

#### Section C: Make sentences using くれる and もらう. [Track: K14-13]
- Example: girlfriend (scarf) → 彼女がマフラーをくれました。 / 彼女にマフラーをもらいました。
- 1. parents (money) => 両親がお金をくれました。 / 両親にお金をもらいました。
- 2. grandfather (radio) => おじいさんがラジオをくれました。 / おじいさんにラジオをもらいました。
- 3. grandmother (gloves) => おばあさんが手袋をくれました。 / おばあさんに手袋をもらいました。
- 4. friend (motorcycle) => 友だちがバイクをくれました。 / 友だちにバイクをもらいました。
- 5. uncle (necktie) => おじさんがネクタイをくれました。 / おじさんにネクタイをもらいました。
- 6. older brother (shirt) => 兄がシャツをくれました。 / 兄にシャツをもらいました。

### Part IV: 新聞を見たらどうですか [Grammar 4: 〜たらどうですか]

#### Section A: Give advice to the people below. [Track: K14-15]
- Example: メアリー / check newspaper → 新聞を見たらどうですか。
- 1. メアリー / consult with the teacher => 先生に相談したらどうですか。
- 2. メアリー / send résumé to companies => 会社に履歴書を送ったらどうですか。
- 3. ジョン / go to a party => パーティーに行ったらどうですか。
- 4. ジョン / join a club => サークルに入ったらどうですか。
- 5. ジョン / give up => あきらめたらどうですか。
- 6. けん / propose marriage => プロポーズしたらどうですか。
- 7. けん / give her a ring => 指輪をあげたらどうですか。
- 8. けん / meet her parents => ご両親に会ったらどうですか。

### Part V: 四時間も勉強しました [Grammar 5: Number + も / しか]

#### Section A: Describe the picture using counters. [Track: K14-16]
- Example: fish (5) → 魚が五匹います。
- 1. cat (3) => 猫が三匹います。
- 2. flower (6) => 花が六本あります。
- 3. necktie (2) => ネクタイが二本あります。
- 4. book (4) => 本が四冊あります。
- 5. radio (1) => ラジオが一台あります。
- 6. shirt (2) => シャツが二枚あります。
- 7. magazine (3) => 雑誌が三冊あります。
- 8. pencil (5) => えんぴつが五本あります。
- 9. mandarin orange (4) => みかんが四個あります。
- 10. plate (3) => お皿が三枚あります。

#### Section B: Describe the pictures using 〜も or 〜しか. [Track: K14-17]
- Example: 勉強しました (4 hours / 30 minutes) → メアリーさんは四時間も勉強しました。 / ジョンさんは三十分しか勉強しませんでした。

## Lesson 15: 長野旅行 (Trip to Nagano)

### Part I: コーヒーを飲もうか [Grammar 1: Volitional Form]

#### Section A: Change the verbs into the volitional forms. [Track: K15-09]
- Example: 行く → 行こう
- 1. 食べる => 食べよう
- 2. 誘う => 誘おう
- 3. 借りる => 借りよう
- 4. 読む => 読もう
- 5. 来る => 来よう
- 6. 待つ => 待とう
- 7. 入る => 入ろう
- 8. 急ぐ => 急ごう
- 9. 話す => 話そう
- 10. 見る => 見よう
- 11. 書く => 書こう
- 12. 予約する => 予約しよう

#### Section B: Suggest your plans to your partner using informal speech. [Track: K15-10]
- Example: drink coffee at a cafe → カフェでコーヒーを飲もう（か）。
- 1. play soccer => サッカーをしよう（か）。
- 2. see a movie in town => 町で映画を見よう（か）。
- 3. take pictures at school => 学校で写真を撮ろう（か）。
- 4. swim in a pool => プールで泳ごう（か）。
- 5. buy hamburgers at McDonald's => マクドナルドでハンバーガーを買おう（か）。
- 6. eat boxed lunches in a classroom => 教室でお弁当を食べよう（か）。
- 7. climb a mountain => 山に登ろう（か）。
- 8. have a barbecue at a park => 公園でバーベキューをしよう（か）。

### Part II: 運動しようと思っています [Grammar 2: 〜ようと思っています]

#### Section A: Describe what each person is planning to do. [Track: K15-12]
- Example: メアリー (have various experiences in Japan) → メアリーさんは日本でいろいろな経験をしようと思っています。
- 1. ナオミ (do physical exercise) => ナオミさんは運動しようと思っています。
- 2. 山下先生 (go on a diet) => 山下先生はダイエットしようと思っています。
- 3. カルロス (quit smoking) => カルロスさんはたばこをやめようと思っています。
- 4. ヤスミン (make lots of Japanese friends) => ヤスミンさんは日本人の友だちをたくさん作ろうと思っています。
- 5. ロバート (practice Japanese all day) => ロバートさんは一日中日本語を練習しようと思っています。
- 6. ソラ (look into Japanese customs) => ソラさんは日本の習慣を調べようと思っています。
- 7. ウデイ (look for a job in Japan) => ウデイさんは日本で仕事を探そうと思っています。
- 8. ジョン (participate in volunteer activity) => ジョンさんはボランティア活動に参加しようと思っています。

### Part III: お金を借りておきます [Grammar 3: 〜ておく]

#### Section A: Say what the people will do in advance. [Track: K15-13]
- Example: ゆい (電池を買う) → ゆいさんは電池を買っておきます。
- 1. メアリー (水と食べ物を買う) => メアリーさんは水と食べ物を買っておきます。
- 2. ヤスミン (お金をおろす) => ヤスミンさんはお金をおろしておきます。
- 3. ロバート (お金を借りる) => ロバートさんはお金を借りておきます。
- 4. 山下先生 (うちを売る) => 山下先生はうちを売っておきます。
- 5. ソラ (保険に入る) => ソラさんは保険に入っておきます。
- 6. けん (大きい家具を捨てる) => けんさんは大きい家具を捨てておきます。
- 7. たけし (たくさん食べる) => たけしさんはたくさん食べておきます。

### Part IV: 韓国に住んでいる友だち [Grammar 4: Qualifying Nouns]

#### Section A: Explain photos using noun phrases. [Track: K15-14]
- Example: a friend who lives in Korea → 韓国に住んでいる友だち
- 1. a friend who can speak Spanish => スペイン語が話せる友だち
- 2. a watch I got from my girlfriend => 彼女にもらった時計
- 3. a friend who went to China last year => 去年中国に行った友だち
- 4. a bag I use every day => 毎日使っているかばん
- 5. a cafe I sometimes go to => 時々行くカフェ
- 6. a temple I saw last week => 先週見たお寺
- 7. a T-shirt I bought in Hawaii => ハワイで買ったTシャツ
- 8. the house I live in now => 今住んでいる家

#### Section D: Combine the two sentences into one sentence. [Track: K15-16]
- Example: コーヒーを飲んでみました。(田中さんにもらいました) → 田中さんにもらったコーヒーを飲んでみました。
- 1. 料理はおいしくないです。(妹が作りました) => 妹が作った料理はおいしくないです。
- 2. 人と結婚したくないです。(料理ができません) => 料理ができない人と結婚したくないです。
- 3. 外国人を探しています。(日本の習慣についてよく知っています) => 日本の習慣についてよく知っている外国人を探しています。
- 4. 人にもう一度会いたいです。(去年の夏に会いました) => 去年の夏に会った人にもう一度会いたいです。
- 5. 人とルームメイトになりたくないです。(よくしゃべります) => よくしゃべる人とルームメイトになりたくないです。
- 6. 会社はこの建物の中にあります。(おじさんが働いています) => おじさんが働いている会社はこの建物の中にあります。
- 7. 冬休みに旅館に泊まろうと思っています。(温泉があります) => 冬休みに温泉がある旅館に泊まろうと思っています。
- 8. 留学に興味があるんですが、学生を知っていますか。(アメリカに留学したことがあります) => アメリカに留学したことがある学生を知っていますか。

## Lesson 16: 忘れ物 (Lost and Found)

### Part I: 晩ご飯を作ってあげました [Grammar 1: 〜てあげる / てくれる / てもらう]

#### Section A: Your friend is sick. Say what you did with 〜てあげる. [Track: K16-09]
- Example: cook dinner → 晩ご飯を作ってあげました。
- 1. be with them => 一緒にいてあげました。
- 2. help with their homework => 宿題を手伝ってあげました。
- 3. correct their paper => 作文を直してあげました。
- 4. buy flowers => 花を買ってあげました。
- 5. take them to the hospital => 病院に連れていってあげました。
- 6. do laundry => 洗濯してあげました。
- 7. clean their room => 部屋を掃除してあげました。
- 8. lend them your notebook => ノートを貸してあげました。
- 9. send an e-mail to their teacher => 先生にメールを送ってあげました。
- 10. do dishes => お皿を洗ってあげました。

#### Section C: State what people did for you with 〜てくれる and 〜てもらう. [Track: K16-10/11]
- Example: ホストファミリー / ご飯を作る → ホストファミリーがご飯を作ってくれました。 / ホストファミリーにご飯を作ってもらいました。
- 1. ホストファミリー / 部屋を掃除する => ホストファミリーが部屋を掃除してくれました。 / 掃除してもらいました。
- 2. ホストファミリー / 洗濯する => ホストファミリーが洗濯してくれました。 / 洗濯してもらいました。
- 3. ホストファミリー / アイロンをかける => ホストファミリーがアイロンをかけてくれました。 / かけてもらいました。
- 4. ホストファミリー / 迎えに来る => ホストファミリーが迎えに来てくれました。 / 来てもらいました。
- 5. 友だち / コーヒーをおごる => 友だちがコーヒーをおごってくれました。 / おごってもらいました。
- 6. 友だち / 京都に連れていく => 友だちが京都に連れていってくれました。 / 連れていってもらいました。
- 7. 友だち / セーターを編む => 友だちがセーターを編んでくれました。 / 編んでもらいました。
