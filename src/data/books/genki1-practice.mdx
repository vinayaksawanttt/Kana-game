- 2. あした テスト ある？ => うん、ある。 / ううん、ない。
- 3. コーヒー のむ？ => うん、のむ。 / ううん、のまない。
- 4. にほんご おもしろい？ => うん、おもしろい。

### Part III: 〜と思います (I Think That...) [Grammar 3]

#### Section A: Express thoughts using 〜とおもいます. [Track: K08-11]
- Example: たけしさんは かっこいい → たけしさんは かっこいいと おもいます。

- 2. にほんごは おもしろい => にほんごは おもしろいと おもいます。
- 3. メアリーさんは こない => メアリーさんは こないと おもいます。
- 4. やましたせんせいは いそがしい => やましたせんせいは いそがしいと おもいます。

### Part IV: 〜と言っていました (They Said That...) [Grammar 4]

#### Section A: Report what people said using 〜といっていました. [Track: K08-12]
- Example: ロバート: 「いそがしいです」 → ロバートさんは いそがしいと いっていました。
- 1. たけし: 「テニスを します」 => たけしさんは テニスを すると いっていました。
- 2. メアリー: 「くるまを かいました」 => メアリーさんは くるまを かったと いっていました。
- 3. ソラ: 「こんばん パーティーが ある」 => ソラさんは こんばん パーティーが あると いっていました。

### Part V: 〜ないでください (Please Don't...) [Grammar 5]

#### Section A: Make negative requests using 〜ないでください. [Track: K08-13]
- Example: しゃしんを とる → しゃしんを とらないでください。
- 1. ここで たべる => ここで たべないでください。
- 2. わすれる => わすれないでください。
- 3. しんぱいする => しんぱいしないでください。
- 4. たばこを すう => たばこを すわないでください。

### Part VI: 〜のが好きです (Nominalizer の) [Grammar 6]

#### Section A: State what you like / are good at doing using 〜のがすき / じょうず. [Track: K08-14]

- 3. テニスを する (bad at) => テニスを するのが へたです。
- 4. えを かく (like) => えを かくのが すきです。

## Lesson 10: 冬休み (Winter Vacation)
