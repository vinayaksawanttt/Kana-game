# Dakuten, Handakuten & Combined Sounds (濁音・半濁音・拗音)

While the basic Gojūon chart contains 46 characters, Japanese expands its phonetic inventory using diacritical marks (**Dakuten** and **Handakuten**) and digraph contractions (**Yōon**).

---

## 1. Dakuten (濁音 / Dakuon) — The Voiced Mark (`゛`)

Adding two small parallel diagonal marks (`゛`, colloquially called **tenten** / 点々) turns unvoiced consonants into their **voiced counterparts** by activating vocal cord vibration:

**K → G** · **S → Z / J** · **T → D / J / Z** · **H → B**

### Complete Dakuten Grid (Hiragana / Katakana)

| Row | **a** | **i** | **u** | **e** | **o** |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **G (from K)** | が / ガ (*ga*) | ぎ / ギ (*gi*) | ぐ / グ (*gu*) | げ / ゲ (*ge*) | ご / ゴ (*go*) |
| **Z (from S)** | ざ / ザ (*za*) | **じ / ジ (*ji*)** | ず / ズ (*zu*) | ぜ / ゼ (*ze*) | ぞ / ゾ (*zo*) |
| **D (from T)** | だ / ダ (*da*) | **ぢ / ヂ (*ji*)** | **づ / ヅ (*zu*)** | で / デ (*de*) | ど / ド (*do*) |
| **B (from H)** | ば / バ (*ba*) | び / ビ (*bi*) | ぶ / ブ (*bu*) | べ / ベ (*be*) | ぼ / ボ (*bo*) |

## 2. The Modern Merger: じ vs. ぢ and ず vs. づ (四つ仮名 / Yotsugana)

In standard modern Tokyo Japanese, the historical 4-way distinction (*di, zi, du, zu*) has merged into 2 phonemes:
- **じ and ぢ** are both pronounced identically as **/d͡ʑi/** or **/ʑi/** (*ji*).
- **ず and づ** are both pronounced identically as **/d͡zɯ/** or **/zɯ/** (*zu*).

> [!NOTE] When to use ぢ and づ
> Modern spelling orthography reserves **ぢ** and **づ** almost exclusively for:
> 1. **Compounds resulting from Rendaku (sequential voicing)**:
>    - はな (*hana* - nose) + **ち** (*chi* - blood) → **はなぢ** (*hanaji* - nosebleed)
>    - みかづき (三日月 - crescent moon: *mika* + *tsuki* → *tsu* becomes *dzu*)
>    - て (*te* - hand) + **つなぐ** (*tsunagu*) → **てづな** (*tedzuna* - reins)
> 2. **Repeated sounds (reduplication)**:
>    - **つづく** (続く / *tsudzuku* - to continue)
>    - **ちぢむ** (縮む / *chidjimu* - to shrink)
> 
> In all other generic vocabulary, **じ** and **ず** are used by default (e.g., 水 / みず *mizu*, 時間 / じかん *jikan*).

## 3. Handakuten (半濁音 / Handakuon) — The Semi-Voiced Mark (`゜`)

Adding a small hollow circle (`゜`, colloquially called **maru** / 丸) only applies to the **H-row**, transforming it into the unvoiced bilabial plosive **P-sound**:

**H → P**

| Row | **a** | **i** | **u** | **e** | **o** |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **P (from H)** | ぱ / パ (*pa*) | ぴ / ピ (*pi*) | ぷ / プ (*pu*) | ぺ / ペ (*pe*) | ぽ / ポ (*po*) |

- **Examples**: パン (*pan* - bread), きっぷ (切符 / *kippu* - ticket), えんぴつ (鉛筆 / *enpitsu* - pencil).

## 4. Contracted Sounds (拗音 / Yōon) — Small ゃ, ゅ, ょ

Yōon sounds are formed by taking an **i-column character** and appending a subscript **small ゃ (*ya*), ゅ (*yu*), or ょ (*yo*)**.

> [!IMPORTANT] Single Syllable (1 Mora) Rule
> A Yōon combination represents a single blended sound and takes **exactly one mora (one rhythmic beat)** of time:
> - **き (1 beat) + ゃ (small) = きゃ (kya — 1 beat total)**.
> - Contrast with full-sized **きや (ki-ya — 2 distinct beats)**!

### Unvoiced Yōon Grid (21 Combinations)

| Base | + ゃ / ャ (*ya*) | + ゅ / ュ (*yu*) | + ょ / ョ (*yo*) | Vocabulary Example |
| :--- | :---: | :---: | :---: | :--- |
| **き / キ (*ki*)** | きゃ / キャ (*kya*) | きゅ / キュ (*kyu*) | きょ / キョ (*kyo*) | 今日 (きょう / *kyō* - today) |
| **し / シ (*shi*)** | **しゃ / シャ (*sha*)** | **しゅ / シュ (*shu*)** | **しょ / ショ (*sho*)** | 写真 (しゃしん / *shashin* - photo) |
| **ち / チ (*chi*)** | **ちゃ / チャ (*cha*)** | **ちゅ / チュ (*chu*)** | **ちょ / チョ (*cho*)** | お茶 (おちゃ / *ocha* - green tea) |
| **に / ニ (*ni*)** | にゃ / ニャ (*nya*) | にゅ / ニュ (*nyu*) | にょ / ニョ (*nyo*) | 牛乳 (ぎゅうにゅう / *gyūnyū* - milk) |
| **ひ / ヒ (*hi*)** | ひゃ / ヒャ (*hya*) | ひゅ / ヒュ (*hyu*) | ひょ / ヒョ (*hyo*) | 百 (ひゃく / *hyaku* - 100) |
| **み / ミ (*mi*)** | みゃ / ミャ (*mya*) | みゅ / ミュ (*myu*) | みょ / ミョ (*myo*) | 名字 (みょうじ / *myōji* - surname) |
| **り / リ (*ri*)** | りゃ / リャ (*rya*) | りゅ / リュ (*ryu*) | りょ / リョ (*ryo*) | 旅行 (りょこう / *ryokō* - travel) |

## 5. Critical Distinction: Small vs. Full-Sized Kana Minimal Pairs

Failing to pronounce small ゃ/ゅ/ょ as a 1-mora contraction creates severe communication misunderstandings:

| Word A (Small Kana / Contracted) | Meaning | Word B (Full-Sized Kana / Distinct Morae) | Meaning |
| :--- | :--- | :--- | :--- |
| **びょういん** (*byō-in* — 4 morae) | **Hospital** (病院) | **びよういん** (*bi-yō-in* — 5 morae) | **Beauty Salon** (美容院) |
| **じゅう** (*jū* — 2 morae) | **Ten** (十) / Gun (銃) | **じゆう** (*ji-yū* — 3 morae) | **Freedom** (自由) |
| **きょう** (*kyō* — 2 morae) | **Today** (今日) | **きよう** (*ki-yō* — 3 morae) | **Dexterous / Skillful** (器用) |
| **りょかん** (*ryo-kan* — 3 morae) | **Traditional Inn** (旅館) | **りよかん** (*ri-yo-kan* — 4 morae) | **Sense of utility** (利用感) |
