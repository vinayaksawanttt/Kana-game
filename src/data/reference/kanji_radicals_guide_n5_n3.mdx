# Kanji Radicals (部首 / Bushu): The Essential 50

Every kanji character is constructed from structural building blocks. In traditional lexicography, every character is indexed under one of the **214 Kangxi Radicals (部首 / *bushu*)**. 

Understanding radicals transforms kanji from intimidating tangles of strokes into logical, modular compounds. Just **50 high-frequency radicals account for more than 80% of all Joyo kanji**.

---

## 1. The 7 Structural Radical Positions

A radical is named according to its spatial position within the kanji frame:

```
  ┌─────────┬─────────┐   ┌───────────────────┐   ┌───────────────────┐
  │         │         │   │   3. 冠 (Top)     │   │ 5. 垂 (Top-Left)  │
  │ 1. 偏   │ 2. 旁   │   ├───────────────────┤   │ ┌─────────────────┤
  │  (Left) │ (Right) │   │                   │   │ │                 │
  │         │         │   ├───────────────────┤   │ │                 │
  │         │         │   │   4. 脚 (Bottom)  │   │ │                 │
  └─────────┴─────────┘   └───────────────────┘   └─┴─────────────────┘

  ┌───────────────────┐   ┌───────────────────┐
  │                   │   │ 7. 構 (Enclosure) │
  │ 6. 繞 (Left-Bott) │   │ ┌───────────────┐ │
  │ ┌─────────────────┤   │ │               │ │
  │ └─────────────────┘   │ └───────────────┘ │
  └───────────────────┘   └───────────────────┘
```

## 3. Two Crucial Radical Distinctions

> [!IMPORTANT] 1. The Tale of Two Ears: 阝 Left vs. 阝 Right
> The element **阝** represents two completely different Kangxi radicals depending on which side it appears:
> - **Left Side (こざとへん / *kozatohen*)**: Derived from **阜 (earthen hill/steps)**. Appears in terrain/building words: **防** (defend), **階** (stairs), **院** (institution).
> - **Right Side (おおざと / *ōzato*)**: Derived from **邑 (settlement/city)**. Appears in municipal/geographical words: **都** (metropolis), **部** (division), **郊** (suburbs).

> [!IMPORTANT] 2. The Flesh Radical (肉月 / Nikuzuki) vs. The Moon Radical (月)
> When **月** appears on the left of body parts (**胸** chest, **腰** hip, **腕** arm, **腹** stomach, **脳** brain, **肌** skin), it is NOT the moon! It is an ancient pictograph of a slab of **meat (肉)** whose strokes compressed to resemble 月. True moon kanji relate to time and illumination (**期** period, **望** full moon/hope, **朝** morning).
