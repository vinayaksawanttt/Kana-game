# Small っ, Long Vowels & Extended Katakana (促音・長音・外来語表記)

Japanese is an **isochronous, mora-timed language**: every single **mora (拍 / *haku*)** occupies the exact same temporal duration. Unlike English, where stressed syllables are stretched and unstressed syllables compressed, cutting a Japanese vowel short or skipping a silent consonant hold completely alters the word's lexical meaning.

---

## 1. Small っ / ッ (促音 / Sokuon) — The Double Consonant Pause

The small **っ** (Hiragana) or **ッ** (Katakana) is known as the **Sokuon (促音)**. It is **never** pronounced as *"tsu"*. 

Instead, it functions as a **consonant geminate (a 1-mora glottal stop or closure)**, creating a silent pause while your vocal tract prepares the mouth shape of the following consonant:
- Preceding **K**: 持つ $\rightarrow$ がっこう (*ga-k-kō*)
- Preceding **S**: 雑誌 $\rightarrow$ ざっし (*za-s-shi*)
- Preceding **T**: 切手 $\rightarrow$ きって (*ki-t-te*)
- Preceding **P**: 切符 $\rightarrow$ きっぷ (*ki-p-pu*)

### Mora Timing Comparison: Minimal Pairs

| Short Word (No っ) | Mora Count | Meaning | Geminate Word (With Small っ) | Mora Count | Meaning |
| :--- | :---: | :--- | :--- | :---: | :--- |
| **来て** (*ki-te*) | 2 beats | "Come!" | **切手** (*ki-t-te*) | 3 beats | Postage stamp |
| **坂** (*sa-ka*) | 2 beats | Slope / Hill | **作家** (*sa-k-ka*) | 3 beats | Author / Writer |
| **音** (*o-to*) | 2 beats | Sound | **夫** (*o-t-to*) | 3 beats | Husband |
| **火災** (*ka-sai*) | 3 beats | Conflagration / Fire | **喝采** (*ka-s-sai*) | 4 beats | Applause |
| **未定** (*mi-te-i*) | 3 beats | Undecided | **密着** (*mi-t-cha-ku*) | 4 beats | Close contact |

## 2. Long Vowels (長音 / Chōon)

A **long vowel (長音 / *chōon*)** lasts for **two full morae (two rhythmic beats)**. 

### Hiragana Lengthening Rules

| Vowel Column | How to Lengthen | Standard Rule | Key Vocabulary Example |
| :--- | :--- | :--- | :--- |
| **a-column** | Add **あ** | $[a] + a$ | おか**あ**さん (*okāsan* — mother) |
| **i-column** | Add **い** | $[i] + i$ | おに**い**さん (*onīsan* — older brother) |
| **u-column** | Add **う** | $[u] + u$ | く**う**き (*kūki* — air) |
| **e-column** | **Almost always add い** | $[e] + i \rightarrow \bar{e}$ | せんせ**い** (*sensē* — teacher); がくせ**い** (*gakusē* — student) |
| | *Rare Native Exception: Add え* | $[e] + e$ | おね**え**さん (*onēsan* — older sister) |
| **o-column** | **Almost always add う** | $[o] + u \rightarrow \bar{o}$ | と**う**きょう (*Tōkyō*); ひこ**う**き (*hikōki* — airplane) |
| | *Rare Native Exception: Add お* | $[o] + o$ | お**お**きい (*ōkii* — big); と**お**い (*tōi* — far); こ**お**り (*kōri* — ice) |

> [!WARNING] The 7 Common "おお" Exceptions in Native Japanese
> Although 95% of long "o" sounds in Hiragana are spelled with **う**, a handful of vital native Japanese words are historically spelled with **お**:
> 1. **大きい** (おおきい / *ōkii* - big)
> 2. **多い** (おおい / *ōi* - many)
> 3. **遠い** (とおい / *tōi* - far)
> 4. **通り** (とおり / *tōri* - street)
> 5. **氷** (こおり / *kōri* - ice)
> 6. **狼** (おおかみ / *ōkami* - wolf)
> 7. **十** (とお / *tō* - ten)

### Katakana Lengthening: The Chōonpu (ー)
In Katakana, vowel lengthening does not use vowel characters. Instead, it uses a horizontal bar called the **Chōonpu (長音符 / ー)**:
- **コーヒー** (*kōhī* — coffee, 4 beats: コ・ー・ヒ・ー)
- **ケーキ** (*kēki* — cake, 3 beats: ケ・ー・キ)
- **タクシー** (*takushī* — taxi, 4 beats: タ・ク・シ・ー)

> [!TIP] Vertical Writing (縦書き / Tate-gaki)
> When writing Katakana vertically (as in traditional novels or newspapers), the horizontal dash **ー** rotates 90 degrees into a vertical stroke: **｜**.

## 3. Extended Katakana for Foreign Loanwords (外来語)

Because classical Japanese phonology lacks consonants like $[f], [v], [w], [t\int], [d\iota]$, modern Katakana uses compound digraphs featuring **subscript small vowels (ァ, ィ, ゥ, ェ, ォ)** to accurately transcribe modern loanwords (*gairaigo*).

### Complete Extended Katakana Master Grid

| Sound Target | Katakana Digraph | Pronunciation (IPA) | Real-World Loanword Examples |
| :--- | :--- | :--- | :--- |
| **F-Sounds** | **ファ, フィ, フェ, フォ** | $[fa], [fi], [fe], [fo]$ | **ファ**ックス (*fax*), **フィ**リピン (*Philippines*), カ**フェ** (*café*), **フォ**ーク (*fork*) |
| **Ti / Di** | **ティ, ディ** | $[ti], [di]$ | パー**ティ**ー (*party*), **ディ**ズニー (*Disney*), ビル**ディ**ング (*building*) |
| **Tu / Du** | **トゥ, ドゥ** | $[tu], [du]$ | **トゥ**ース (*tooth*), **ドゥ**ーブル (*double*) |
| **W-Sounds** | **ウィ, ウェ, ウォ** | $[wi], [we], [wo]$ | **ウィ**スキー (*whisky*), **ウェ**ブサイト (*website*), **ウォ**ーター (*water*) |
| **V-Sounds** | **ヴァ, ヴィ, ヴ, ヴェ, ヴォ** | $[va], [vi], [vu], [ve], [vo]$ | **ヴァ**イオリン (*violin*), **ヴ**ィーガン (*vegan*), **ヴェ**ネツィア (*Venice*) |
| **She / Je / Che** | **シェ, ジェ, チェ** | $[ʃe], [dʒe], [tʃe]$ | **シェ**ア (*share*), **ジェ**ット (*jet*), **チェ**ック (*check*) |
| **Ts-Sounds** | **ツァ, ツィ, ツェ, ツォ** | $[tsa], [tsi], [tse], [tso]$ | モー**ツァ**ルト (*Mozart*), カンン**ツォ**ーネ (*canzone*) |
| **Kw / Gw** | **クァ, クィ, クェ, クォ** | $[kwa], [kwi], [kwe], [kwo]$ | **クォ**ーター (*quarter*), **クァ**ルテット (*quartet*) |

> [!NOTE] V-Sounds vs. B-Sounds
> While ヴ (with dakuten on ウ) was officially introduced into Japanese government orthography to represent the English [V], in casual daily spoken Japanese and common signage, **バ, ビ, ブ, ベ, ボ** are still universally accepted:
> - **ヴァイオリン** $\longleftrightarrow$ **バイオリン** (*baiorin* — violin)
> - **ヴィタミン** $\longleftrightarrow$ **ビタミン** (*bitamin* — vitamin)
