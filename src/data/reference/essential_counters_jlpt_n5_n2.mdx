# Japanese Counters (助数詞 / Josūshi)

In Japanese, nouns cannot be counted by simply prefixing a bare number (e.g., *"two cats"* is ungrammatical as \*二猫). Instead, a **counter suffix (助数詞 / *josūshi*)** must be appended to the number according to the object's physical shape, biological category, function, or conceptual nature.

---

## Sentence Structure: How to Use Counters in Japanese

There are two primary grammatical patterns for placing counters in a sentence:

### Pattern A: Standard Word Order (Most Common)
Place the counter **directly before the verb**, after the direct object particle **を**:
```
[Noun] を + [Number + Counter] + [Verb]
```
- 本を**三冊**買いました。 (*Hon o san-satsu kaimashita.* — I bought three books.)
- ビールを**二本**ください。 (*Bīru o ni-hon kudasai.* — Two beers, please.)

### Pattern B: Modifying the Noun with の
Place the counter **before the noun**, connected by the particle **の**:
```
[Number + Counter] の + [Noun] + [Particle] + [Verb]
```
- **三人の**学生が来ました。 (*San-nin no gakusei ga kimashita.* — Three students came.)

## 1. The Universal Native Counter: 1 to 10 (〜つ / Tsu)

When you do not know the specific counter for an inanimate, abstract, or irregularly shaped object (orders of food, ideas, questions, small items), use the native Japanese numeral system ending in **〜つ (*-tsu*)**. This system counts from 1 to 10:

| Count | Kanji | Hiragana | Romaji | Meaning / Context |
| :---: | :---: | :--- | :--- | :--- |
| **1** | 一つ | **ひとつ** | *hitotsu* | One thing |
| **2** | 二つ | **ふたつ** | *futatsu* | Two things |
| **3** | 三つ | **みっつ** | *mittsu* | Three things (small っ) |
| **4** | 四つ | **よっつ** | *yottsu* | Four things (small っ) |
| **5** | 五つ | **いつつ** | *itsutsu* | Five things |
| **6** | 六つ | **むっつ** | *muttsu* | Six things (small っ) |
| **7** | 七つ | **ななつ** | *nanatsu* | Seven things |
| **8** | 八つ | **やっつ** | *yattsu* | Eight things (small っ) |
| **9** | 九つ | **ここのつ** | *kokonotsu* | Nine things |
| **10** | 十 | **とお** | *tō* | Ten things (**No 〜つ!**) |
| **?** | 幾つ | **いくつ** | *ikutsu* | How many? |

> [!NOTE] Above 10:
> Beyond 10, native counting ceases. Revert to standard numbers (11, 12, etc.) or specific counters: 十一個 (じゅういっこ *jūikko*).

## 2. Essential Counters by Shape & Nature (JLPT N5–N4)

Counters often cause phonological shifts (**rendaku** to voiced sounds, or **gemination** with small っ) at counts of **1, 3, 6, 8, and 10**:

| Counter | Used For | Base Reading | Irregularities & Sound Shifts |
| :--- | :--- | :--- | :--- |
| **〜人 (にん)** | **People** | *nin* | **1: ひとり (*hitori*)**<br>**2: ふたり (*futari*)**<br>**4: よにん (*yonin*)** (NOT *shinin*) |
| **〜本 (ほん)** | **Long, cylindrical objects** (pens, bottles, trees, umbrellas, bananas, train lines) | *hon* | **1: いっぽん (*ippon*)**<br>**3: さんぼん (*sanbon*)**<br>**6: ろっぽん (*roppon*)**<br>**8: はっぽん (*happon*)**<br>**10: じゅっぽん (*juppon*)**<br>**?: なんぼん (*nanbon*)** |
| **〜枚 (まい)** | **Flat, thin items** (paper, tickets, plates, shirts, photos, coins) | *mai* | **Entirely regular!**<br>1: いちまい, 2: にまい, 3: さんまい, 4: よんまい... ?: なんまい |
| **〜匹 (ひき)** | **Small animals, insects, fish** (cats, dogs, mice, frogs) | *hiki* | **1: いっぴき (*ippiki*)**<br>**3: さんびき (*sanbiki*)**<br>**6: ろっぴき (*roppiki*)**<br>**8: はっぴき (*happiki*)**<br>**10: じゅっぴき (*juppiki*)**<br>**?: なんびき (*nanbiki*)** |
| **〜台 (だい)** | **Machines, vehicles, furniture** (cars, computers, bicycles, TVs) | *dai* | **Entirely regular!**<br>1: いちだい, 4: よんだい, ?: なんだい |
| **〜冊 (さつ)** | **Bound reading material** (books, magazines, notebooks, dictionaries) | *satsu* | **1: いっさつ (*issatsu*)**<br>**8: はっさつ (*hassatsu*)**<br>**10: じゅっさつ (*jussatsu*)** |
| **〜杯 (はい)** | **Cups, glasses, bowls of liquid** (coffee, tea, noodles, rice bowls) | *hai* | **1: いっぱい (*ippai*)**<br>**3: さんばい (*sanbai*)**<br>**6: ろっぱい (*roppai*)**<br>**8: はっぱい (*happai*)**<br>**10: じゅっぱい (*juppai*)**<br>**?: なんばい (*nanbai*)** |
| **〜個 (こ)** | **Small 3D objects, fruits, containers** (apples, eggs, boxes, dice) | *ko* | **1: いっこ (*ikko*)**<br>**6: ろっこ (*rokko*)**<br>**8: はっこ (*hakko*)**<br>**10: じゅっこ (*jukko*)** |

## 3. Spatial, Spatial-Frequency & Building Counters (JLPT N4–N3)

| Counter | Used For | Base Reading | Key Sound Shifts |
| :--- | :--- | :--- | :--- |
| **〜階 (かい)** | **Floors of a building** | *kai* | 1階: いっかい (*ikkai*)<br>**3階: さんがい (*sangai*)** (Voiced!)<br>6階: ろっかい (*rokkai*)<br>8階: はっかい (*hakkai*)<br>**?: なんがい (*nangai*)** |
| **〜回 (かい)** | **Times / Frequency** | *kai* | 1回: いっかい (*ikkai*)<br>6回: ろっかい (*rokkai*)<br>8回: はっかい (*hakkai*)<br>10回: じゅっかい (*jukkai*) |
| **〜度 (ど)** | **Occurrences / Degrees of temp** | *do* | 1度: いちど (*ichido*) (Regular)<br>もう一度: *mō ichido* (once more) |
| **〜軒 (けん)** | **Houses, stores, restaurants** | *ken* | 1軒: いっけん (*ikken*)<br>**3軒: さんげん (*sangen*)** (Voiced!)<br>6軒: ろっけん (*rokken*)<br>8軒: はっけん (*hakken*) |
| **〜足 (そく)** | **Pairs of footwear / socks** | *soku* | 1足: いっそく (*issoku*)<br>**3足: さんぞく (*sanzoku*)** (Voiced!)<br>8足: はっそく (*hassoku*) |
| **〜着 (ちゃく)** | **Suits, dresses, jackets** | *chaku* | 1着: いっちゃく (*icchaku*)<br>3着: さんちゃく |

## Quick Sound Change Master Cheat Sheet

```
When combining with counters starting with H/F (本, 杯, 匹):
  1: ichi + hon -> IP-PON (っ + p)
  3: san  + hon -> SAN-BON (voiced b)
  6: roku + hon -> ROP-PON (っ + p)
  8: hachi+ hon -> HAP-PON (っ + p)
 10: juu  + hon -> JUP-PON (っ + p)
  ?: nan  + hon -> NAN-BON (voiced b)

When combining with counters starting with K (階, 回, 個, 軒):
  1: ichi + kai -> IK-KAI (っ + k)
  3: san  + kai -> SAN-GAI (voiced g for 階 and 軒)
  6: roku + kai -> ROK-KAI (っ + k)
  8: hachi+ kai -> HAK-KAI (っ + k)
 10: juu  + kai -> JUK-KAI (っ + k)
```
