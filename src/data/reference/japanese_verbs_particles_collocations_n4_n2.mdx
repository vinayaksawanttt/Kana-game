# Verbs with Particles and Common Collocations

Japanese verbs have preferred particle patterns. A direct translation from English can lead to the wrong particle, so learn a verb together with its common frame: **人に会う**, **場所に住む**, **道を歩く**.

## 1. Useful verb-particle patterns

| Pattern | Meaning | Example |
| :--- | :--- | :--- |
| 人に会う | meet a person | 駅で友達に会いました。 |
| 人に聞く | ask a person; hear from a person | 先生に答えを聞きました。 |
| 人に相談する | consult someone | 母に進路を相談しました。 |
| 人に電話する | call someone | 店に電話してください。 |
| 場所に住む | live in a place | 東京に住んでいます。 |
| 場所に着く | arrive at a place | 8時に駅に着きます。 |
| 乗り物に乗る | get on / ride a vehicle | バスに乗ります。 |
| 乗り物を降りる | get off a vehicle | 次の駅で電車を降ります。 |
| 人に似ている | resemble a person | 妹は母に似ています。 |
| 物に気づく | notice something | 間違いに気づきました。 |
| 試験に合格する | pass an exam | 試験に合格しました。 |
| 仕事に参加する | participate in an event/activity | 会議に参加します。 |
| 友達と話す | talk with a friend | 友達と日本語で話します。 |
| 友達と結婚する | marry a person | 彼は大学の友達と結婚しました。 |
| 道を歩く | walk along a route | 公園の中を歩きます。 |
| 橋を渡る | cross a bridge | 橋を渡ってください。 |
| 家を出る | leave a house | 7時に家を出ます。 |
| 公園で遊ぶ | play at a place | 子どもが公園で遊んでいます。 |

Particle choices can vary with meaning and context. For example, **人に聞く** means ask a person, while **音を聞く** means listen to a sound. **道を歩く** uses を for the route traversed, not a direct object.

## 2. Frequently tested collocations

| Natural combination | Meaning | Example sentence |
| :--- | :--- | :--- |
| 約束を守る | keep a promise | 約束を守ってください。 |
| ルールを破る | break a rule | 彼はルールを破りました。 |
| 予定を立てる | make a plan / schedule | 旅行の予定を立てています。 |
| 予定を変更する | change a plan | 会議の予定を変更しました。 |
| 連絡を取る | get in touch | 後で連絡を取ります。 |
| 電話をかける | make a phone call | 友達に電話をかけました。 |
| 気をつける | be careful; pay attention | 車に気をつけてください。 |
| 気に入る | like; take a liking to | このかばんが気に入りました。 |
| 興味を持つ | take an interest in | 日本の歴史に興味を持っています。 |

## 3. Compare particles to change the relationship

### に and と with 話す

- 先生**に**話しました。 — I spoke to the teacher.
- 先生**と**話しました。 — I spoke with the teacher.

### に and で with 行く

- 学校**に**行きます。 — I go to school (destination).
- バス**で**学校に行きます。 — I go to school by bus (means).

### を with a direct object or a route

- 本**を**読みます。 — I read a book (object).
- 公園**を**歩きます。 — I walk through the park (route).

## 4. Build a vocabulary card around the pattern

For each new verb, record:

1. Its dictionary form and verb group.
2. Its common particle frame (for example, **人に会う**, **物を見せる**).
3. One natural sentence.
4. Whether it has a transitive/intransitive partner or a fixed collocation.

This method helps remember both what the verb means and how Japanese speakers commonly use it.
