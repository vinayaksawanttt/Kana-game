# The Japanese て-Form

The **て-form** is a verb form used to connect clauses, make requests, form progressive constructions, and attach many common grammar patterns. It is not simply a marker for past or present tense; the ending and surrounding grammar determine the meaning.

## 1. Group 1 (う-verbs): use the final kana

| Dictionary ending | Change | Example |
| :--- | :--- | :--- |
| う, つ, る | って | 買う → 買って; 待つ → 待って; 取る → 取って |
| む, ぶ, ぬ | んで | 飲む → 飲んで; 遊ぶ → 遊んで; 死ぬ → 死んで |
| く | いて | 書く → 書いて |
| ぐ | いで | 泳ぐ → 泳いで |
| す | して | 話す → 話して |

### The important exception: 行く

**行く** becomes **行って**, not *行いて*: 行く → 行って → 行った.

## 2. Group 2 (る-verbs)

Remove final **る**, then add **て**:

| Dictionary form | て-form |
| :--- | :--- |
| 食べる | 食べて |
| 見る | 見て |
| 起きる | 起きて |
| 教える | 教えて |

Check the verb group rather than relying only on the final る. For example, 帰る is Group 1: 帰る → 帰って.

## 3. Irregular verbs

| Dictionary form | て-form |
| :--- | :--- |
| する | して |
| 来る (くる) | 来て (きて) |

## 4. From て-form to た-form

The same sound change makes the plain past form: replace **て** with **た**, and **で** with **だ**.

| て-form | た-form | Dictionary form |
| :--- | :--- | :--- |
| 書いて | 書いた | 書く |
| 泳いで | 泳いだ | 泳ぐ |
| 飲んで | 飲んだ | 飲む |
| 買って | 買った | 買う |
| 食べて | 食べた | 食べる |
| して | した | する |
| 行って | 行った | 行く |

## 5. Common uses

### Connect actions in sequence

て-form can connect actions done in order. The final verb carries the tense:

> 朝ご飯を食べて、学校へ行きました。  
> I ate breakfast and went to school.

### Make a request with ～てください

> ここに名前を書いてください。  
> Please write your name here.

To make a negative request, use **～ないでください**: ここで写真を撮らないでください (Please don't take pictures here).

### Describe an ongoing action or state with ～ている

> 今、本を読んでいます。  
> I am reading a book now.

Depending on the verb, ～ている can also describe a resulting state or habitual action: 結婚しています (is married); 毎朝走っています (runs every morning).

### Ask permission with ～てもいい

> ここに座ってもいいですか。  
> May I sit here?

### Say that something is prohibited with ～てはいけない

> ここで泳いではいけません。  
> You must not swim here.

In speech, ては is often pronounced ちゃ and では as じゃ: 食べちゃだめ (You mustn't eat it).

## 6. A quick checklist

1. Identify whether the verb is Group 1, Group 2, or irregular.
2. For Group 1, look up the final kana in the sound-change table.
3. Check for **行く → 行って**.
4. For Group 2, remove る and add て.
5. Remember that て-form itself does not indicate past tense.
