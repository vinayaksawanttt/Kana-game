# Japanese Conditionals: と vs. ば vs. たら vs. なら

English uses the versatile word *"if"* for almost all conditional scenarios. Japanese, however, employs four distinct conditional structures: **と**, **ば**, **たら**, and **なら**.

Choosing the right conditional depends on whether the outcome is a **natural law**, a **hypothetical stipulation**, a **chronological sequence**, or an **interpersonal assumption**.

---

## Master Comparison Matrix

| Conditional | Core Meaning | Primary Domain | Can Clause B be a Request, Order, or Invitation? |
| :---: | :--- | :--- | :---: |
| **〜と** | Whenever / Natural consequence | Mechanical reactions, natural laws, giving directions | **NO** (Strictly forbidden) |
| **〜ば** | Provided that / Hypothetical condition | General truths, academic logic, minimum conditions | **RESTRICTED** (Only if Clause A is non-action) |
| **〜たら** | Once / If and when (Sequential) | Daily conversation, personal future plans, past discovery | **YES** (Freely permitted) |
| **〜なら** | Given that / If it's true that (Contextual) | Suggestions, advice, evaluating conversational context | **YES** (Freely permitted) |

---

## 1. 〜と: Inevitable & Mechanical Consequence

Attaches directly to the **dictionary form** of verbs or plain predicates.

### Core Nuance: 100% Guaranteed Outcome
When condition A occurs, result B happens automatically, naturally, or mechanically:

1. **Machines & Operations**:
   - このボタンを**押すと**、切符が出ます。  
     *Kono botan o osu to, kippu ga demasu.*  
     (Press this button, and the ticket comes out.)
2. **Natural Laws & Seasons**:
   - 春に**なると**、桜が咲きます。  
     *Haru ni naru to, sakura ga sakimasu.*  
     (When spring arrives, cherry blossoms bloom.)
3. **Directions & Street Navigation**:
   - この道をまっすぐ**行くと**、右側に郵便局があります。  
     *Kono michi o massugu iku to, migigawa ni yūbinkyoku ga arimasu.*  
     (Go straight along this street, and the post office is on the right.)

> [!WARNING]
> **Clause B can never express the speaker's personal volition or command!**  
> Incorrect: \*雨が降ると、家にいましょう。  
> Incorrect: \*安くなると、買ってください。

### Surprise Discovery in the Past
When used with a past tense clause B, **と** describes an unexpected discovery:
- 窓を**開けると**、雪が降っていた。  
  *Mado o akeru to, yuki ga futte ita.*  
  (When I opened the window, [to my surprise] it was snowing.)

---

## 2. 〜ば: Hypothetical Proviso ("Provided That...")

Formed by moving the final kana to the **え-row + ば** (書く → 書けば; 食べる → 食べれば; 安い → 安ければ; 静か → 静かなら).

### Core Nuance: The Essential Condition
Focuses on the logical link between a premise and its outcome ("Provided condition A is met, outcome B is achieved"):

- 薬を**飲めば**、治ります。  
  *Kusuri o nomeba, naorimasu.*  
  (Provided you take the medicine, you will recover.)
- 安**ければ**、買います。  
  *Yasukereba, kaimasu.*  
  (If it is cheap, I will buy it.)
- 練習す**れば**するほど、上手になる。  
  *Renshū sureba suru hodo, jōzu ni naru.*  
  (The more one practices, the more skillful one becomes. [Proverbial format])

### Clause B Volition Constraint
If Clause A is an active, volitional action performed by a human, Clause B **cannot** contain a command or request.  
- Incorrect: \*東京へ行けば、連絡してください。  
- Correct: 東京へ**行ったら**、連絡してください。 (*Use たら instead!*)

*(Exception: If Clause A is a state or adjective, Clause B can take a request: 安ければ買ってください。)*

---

## 3. 〜たら: Chronological Sequence ("Once A, then B")

Formed by taking the **past tense (た-form) + ら** (行ったら, 食べたら, 寒かったら, 静かだったら).

### Core Nuance: Sequential Completion
Emphasizes that **action A must be completely finished before action B begins**:

- 家に**着いたら**、電話してください。  
  *Ie ni tsuitara, denwa shite kudasai.*  
  (Once you have arrived home, please phone me. [A finishes, then B happens])
- 映画が**終わったら**、ご飯を食べに行きましょう。  
  *Eiga ga owattara, gohan o tabe ni ikimashō.*  
  (Once the movie finishes, let's go eat a meal.)

### The Universal Conversational Conditional
Because **たら** has **no grammatical restrictions on Clause B**, it is the default conditional in spoken Japanese whenever you want to make an order, request, suggestion, or personal plan:
- 雨が**降ったら**、タクシーで行きます。 (*If it rains, I'll go by taxi.*)
- 分からなかっ**たら**、先生に聞いてください。 (*If you don't understand, ask the teacher.*)

---

## 4. 〜なら: Contextual & Topical Assumption

Formed by appending **なら** directly to a noun or plain predicate (often picking up a topic mentioned by the other speaker).

### Core Nuance: "Given that..." / "If you're talking about..."
Takes information introduced into the conversation and provides advice, suggestions, or requirements:

- **A**: 来週、京都へ旅行に行くんですよ。 (*I'm traveling to Kyoto next week.*)  
  **B**: 京都へ**行くなら**、清水寺がおすすめですよ！ (*If you're going to Kyoto, Kiyomizu-dera is recommended!*)

### Unique Feature: Clause B Can Happen BEFORE Clause A!
With **たら**, A must happen before B. With **なら**, action B can occur **in advance of** action A:

```
たら (Sequential):      日本に行ったら、本を買います。
                        (Arrive in Japan FIRST ──► buy books second)

なら (Preparatory):     日本に行くなら、ビザを取ってください。
                        (Apply for visa FIRST ──► travel to Japan second!)
```

## 5. Comparative Scenario: "Spring Arrives" (春になる)

Compare how changing the conditional alters the entire communicative intention:

| Sentence | Meaning & Implication |
| :--- | :--- |
| 春に**なると**、桜が咲く。 | Natural law: When spring comes, cherry blossoms bloom automatically. |
| 春に**なれば**、暖かくなる。 | Hypothetical logic: Provided spring arrives, it will warm up. |
| 春に**なったら**、ピクニックに行こう！ | Sequence + Invitation: Once spring gets here, let's go on a picnic! |
| 春**なら**、京都の桜が一番だ。 | Contextual topic: If we're talking about spring, Kyoto's sakura is best. |

## Summary Decision Flowchart

```
Does clause B contain an order, request, invitation, or intention (〜て, 〜たい, 〜ましょう)?
  │
  ├─► YES ──► Does clause B occur BEFORE action A (e.g., preparation)?
  │             ├─► YES ──► Use なら (日本に行くならビザを取れ)
  │             └─► NO  ──► Use たら (日本に着いたら電話して)
  │
  └─► NO
        ├─► Is it an automatic machine response or natural law?
        │     └─► YES ──► Use と (ボタンを押すと切符が出る)
        │
        ├─► Is it a general logical condition ("Provided that...")?
        │     └─► YES ──► Use ば (安ければ買う)
        │
        └─► Is it a conversational past discovery or chronological event?
              └─► YES ──► Use たら (窓を開けたら雪だった)
```
