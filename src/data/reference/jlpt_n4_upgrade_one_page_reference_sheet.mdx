# JLPT N4 Upgrade Sheet: The One-Page Grammar Matrix (N4必須文法シート)

Passing **JLPT N4** represents the transition from basic survival phrases to genuine interactive Japanese. N4 introduces complex verb inflections (voices), interpersonal social dynamics (giving and receiving), multi-clause conditionals, and conversational keigo. 

Keep this reference card open to master the leap from N5 to N4.

---

## 1. The 4 Major Verb Voices (動詞の「態」4大活用)

Mastering these four voice transformations is the single most tested skill on JLPT N4:

```
┌────────────────────────────────────────────────────────┐
│  1. 可能形 (Potential):          Can do / Able to do    │
│  2. 受身形 (Passive):            Is done to / Affected  │
│  3. 使役形 (Causative):          Make / Let someone do  │
│  4. 使役受身 (Causative-Passive): Forced to do by someone│
└────────────────────────────────────────────────────────┘
```

| Verb Group | Base Verb | 1. Potential (可能) | 2. Passive (受身) | 3. Causative (使役) | 4. Causative-Passive (使役受身) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **G1 (五段)** | 書く (*kaku*) | 書**ける** (*kakeru*) | 書**かれる** (*kakareru*) | 書**かせる** (*kakaseru*) | 書**かされる** (*kakasaseru/kakasareru*) |
| **G1 (五段)** | 飲む (*nomu*) | 飲**める** (*nomeru*) | 飲**まれる** (*nomareru*) | 飲**ませる** (*nomaseru*) | 飲**まされる** (*nomasareru*) |
| **G1 (五段)** | 待つ (*matsu*) | 待**てる** (*materu*) | 待**たれる** (*matareru*) | 待**たせる** (*mataseru*) | 待**たされる** (*matasareru*) |
| **G2 (一段)** | 食べる (*taberu*) | 食べ**られる** (*taberareru*) | 食べ**られる** (*taberareru*) | 食べ**させる** (*tabesaseru*) | 食べ**させられる** (*tabesaserareru*) |
| **G2 (一段)** | 見る (*miru*) | 見**られる** (*mirareru*) | 見**られる** (*mirareru*) | 見**させる** (*misaseru*) | 見**させられる** (*misaserareru*) |
| **G3 (不規則)** | する (*suru*) | **できる** (*dekiru*) | **される** (*sareru*) | **させる** (*saseru*) | **させられる** (*saserareru*) |
| **G3 (不規則)** | 来る (*kuru*) | **来られる** (*korareru*) | **来られる** (*korareru*) | **来させる** (*kosaseru*) | **来させられる** (*kosaserareru*) |

> [!TIP]
> Notice the particle shift for **Potential Verbs**: the direct object particle **を** usually shifts to **が**:
> - 漢字**を**書く (I write kanji) ➔ 漢字**が**書ける (I can write kanji).

## 2. Giving and Receiving Expressions (授受表現: Ageru, Kureru, Morau)

Understanding who performs the action and who receives the benefit is vital:

```
[Giver] は [Recipient] に あげる        ──► Giver gives to someone else
[Giver] は [私に] くれる              ──► Giver gives to ME (or my in-group family)
[Recipient/Me] は [Giver] に/から もらう ──► Recipient receives from Giver
```

### Performing Actions as Favors (〜てあげる / 〜てくれる / 〜てもらう)
- **〜てあげる**: I do something for someone else: *友だちに日本語を教えてあげました。*
- **〜てくれる**: Someone does a favor for ME: *田中さんが駅まで車で送ってくれました。*
- **〜てもらう**: I receive the favor of someone doing something: *先生に作文を直してもらいました。*
- **〜ていただけませんか**: Ultra-polite request ("Could you please do for me?"): *もう一度説明していただけませんか。*

## 3. The 4 Conditionals Master Matrix (条件形: と, ば, たら, なら)

| Conditional | Formation | Core Nuance & Function | Golden Rule / Limitation |
| :---: | :--- | :--- | :--- |
| **〜と** | Dict Form + と | **Natural / Inevitable consequence**: "Whenever X happens, Y always follows." | ⚠️ **Never use requests, orders, or volitional actions in the second clause!** (e.g. 春になると、桜が咲く). |
| **〜ば** | -u ➔ -eba (書けば / 食べれば) | **Hypothetical condition**: "Provided that X is true, then Y." | Academic / theoretical focus (e.g. 安ければ、買います). |
| **〜たら** | Ta-form + ら (飲んだら / 食べたら) | **Temporal sequence & Past discovery**: "When/after X happens..." | **The most versatile conditional**; permits requests and future actions (e.g. 家に着いたら、電話して). |
| **〜なら** | Noun / Plain + なら | **Contextual topic condition**: "If we are talking about X / in that case..." | Offers advice based on what the listener just said (e.g. 京都へ行くなら、金閣寺がおすすめ). |

## 4. Auxiliary Verbs & Aspect (補助動詞・アスペクト)

- **〜てしまう (*...te shimau*)**:
  1. Complete action finished: *宿題を全部やってしまいました。*
  2. Unintentional mistake / regret: *電車の中に傘を忘れてしまいました。*
- **〜ておく (*...te oku*)**: Action done in advance for future convenience: *旅行の前に、切符を買っておきます。*
- **〜てみる (*...te miru*)**: Try doing something to see what happens: *日本の納豆を食べてみました。*
- **〜てある (*...te aru*)**: State resulting from purposeful human action (with Intransitive meaning + が): *カレンダーに予定が書いてあります。*
- **〜ている (*...te iru*)**: Resultant state (e.g., *窓が開いている* — The window is open).

## 5. Intentions, Decisions, and Changes

| Pattern | Meaning | Example |
| :--- | :--- | :--- |
| **〜つもりだ** | Intention / Plan | 来年、日本へ留学する**つもりです**。 (I intend to study abroad in Japan next year.) |
| **〜予定だ** | Official schedule | 明日、会議が開かれる**予定です**。 (A meeting is scheduled to be held tomorrow.) |
| **〜ようになる** | Gradual change in ability | 日本語のニュースが読める**ようになりました**。 (I have become able to read Japanese news.) |
| **〜ようにする** | Deliberate conscious effort/habit | 毎日野菜を食べる**ようにしています**。 (I make an effort to eat vegetables every day.) |
| **〜ことにする** | Personal deliberate decision | 今日からタバコをやめる**ことにしました**。 (I have decided to quit smoking starting today.) |
| **〜ことになる** | Decision made by external rule/others | 来月、大阪支社へ転勤する**ことになりました**。 (It has been decided that I will transfer to Osaka.) |

## 6. Hearsay, Appearance, and Conjecture

- **〜そうだ (Appearance: Looks like...)**:
  - Formation: Verb Stem / Adjective Stem + そうだ.
  - *雨が降りそうだ。* (It looks like it will rain soon.)
  - *このケーキ、おいしそうだね。* (This cake looks delicious, huh.)
- **〜そうだ (Hearsay: I heard that...)**:
  - Formation: Plain Form + そうだ.
  - *明日は雪が降るそうだ。* (I heard that it will snow tomorrow.)
- **〜ようだ / 〜みたいだ (Metaphor / Sensory conjecture)**:
  - *彼はまるで子どものようだ。* (He is just like a child.)
- **〜らしい (Conjecture based on evidence / typical representation)**:
  - *田中さんは風邪を引いたらしい。* (It seems Tanaka caught a cold.)

## 7. Basic Keigo Foundations (敬語の基礎)

| Type | Regular Derivation Formula | Special Irregular Verbs |
| :--- | :--- | :--- |
| **尊敬語** (*Sonkeigo*: Elevates listener) | **お／ご + Stem + になる**<br/>(先生が**お帰りになります**) | 行く/来る/いる ➔ **いらっしゃる**<br/>言う ➔ **おっしゃる**<br/>食べる/飲む ➔ **召し上がる**<br/>する ➔ **なさる** |
| **謙譲語** (*Kenjōgo*: Lowers oneself) | **お／ご + Stem + する / いたす**<br/>(私が荷物を**お持ちします**) | 行く/来る ➔ **参る** (*mairu*)<br/>言う ➔ **申す** (*mōsu*)<br/>食べる/飲む/もらう ➔ **いただく**<br/>する ➔ **いたす** |
