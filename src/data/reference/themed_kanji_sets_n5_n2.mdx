# Themed Kanji Sets (テーマ別漢字マスター)

Studying kanji in **semantic clusters (thematic groups)** activates associative memory networks, making readings and vocabulary far easier to retain than arbitrary alphabetical or frequency lists.

Each section below organizes characters from foundational **N5/N4** vocabulary up through **N3/N2** intermediate terminology.

---
