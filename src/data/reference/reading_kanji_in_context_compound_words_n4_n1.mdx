# Reading Kanji in Context: Compound Words (文脈で読む熟語と漢字)

In written Japanese, multi-kanji compound words (**熟語 — *Jukugo***) convey dense, precise academic, technical, and cultural meaning. Rather than memorizing every compound as a random string of characters, understanding the **internal logical structure of compounds** allows you to deduce the meaning and pronunciation of unfamiliar words on the JLPT (N4–N1).

---

## 1. The 5 Structural Types of Jukugo (熟語の5大構成)

Almost every two-kanji compound falls into one of five structural categories:

```
┌────────────────────────────────────────────────────────┐
│             The 5 Internal Jukugo Structures           │
├────────────────────────────────────────────────────────┤
│ Type 1: Synonym Combination  (似た意味の組み合わせ)    │
│ Type 2: Antonym Combination  (反対の意味の組み合わせ)  │
│ Type 3: Modifier + Modified  (修飾・被修飾の関係)      │
│ Type 4: Verb + Object        (動詞＋目的語・補語)       │
│ Type 5: Negation + Word      (否定の接頭辞＋語)        │
└────────────────────────────────────────────────────────┘
```

| Structure Type | Mechanism | Examples | Structural Breakdown |
| :--- | :--- | :--- | :--- |
| **1. Synonym Pair** (類義) | Two characters with similar meanings combine to reinforce the concept. | **死亡** (*shi-bō*)<br/>**援助** (*en-jo*)<br/>**増加** (*zō-ka*)<br/>**温暖** (*on-dan*) | 死 (die) + 亡 (perish) = Death<br/>援 (aid) + 助 (assist) = Assistance<br/>増 (increase) + 加 (add) = Growth<br/>温 (warm) + 暖 (mild) = Warm climate |
| **2. Antonym Pair** (対義・反対) | Two opposing characters combine to express a broader scale or spectrum. | **寒暖** (*kan-dan*)<br/>**勝敗** (*shō-hai*)<br/>**左右** (*sa-yū*)<br/>**伸縮** (*shin-shuku*) | 寒 (cold) + 暖 (warm) = Temperature<br/>勝 (win) + 敗 (lose) = Outcome/result<br/>左 (left) + 右 (right) = Influence/sides<br/>伸 (expand) + 縮 (contract) = Elasticity |
| **3. Modifier + Modified** (修飾) | The upper character acts like an adjective or adverb describing the lower character. | **高原** (*kō-gen*)<br/>**急行** (*kyū-kō*)<br/>**青空** (*ao-zora*)<br/>**深夜** (*shin-ya*) | 高 (high) + 原 (plain) = Plateau<br/>急 (fast) + 行 (travel) = Express train<br/>青 (blue) + 空 (sky) = Clear blue sky<br/>深 (deep) + 夜 (night) = Late night |
| **4. Verb + Object / Inverted** (述語＋目的語) | Read in reverse order (lower kanji is the object/target of the upper verb). | **読書** (*doku-sho*)<br/>**登山** (*to-zan*)<br/>**飲酒** (*in-shu*)<br/>**帰国** (*ki-koku*) | 書 (books) を 読 (read) ➔ Reading books<br/>山 (mountain) に 登 (climb) ➔ Mountaineering<br/>酒 (alcohol) を 飲 (drink) ➔ Alcohol consumption<br/>国 (home country) に 帰 (return) ➔ Return home |
| **5. Negation Prefix** (否定語) | Upper character negates the lower character (不, 無, 未, 非). | **不安** (*fu-an*)<br/>**無限** (*mu-gen*)<br/>**未定** (*mi-tei*)<br/>**非常** (*hi-jō*) | 不 (not) + 安 (peaceful) = Anxiety<br/>無 (without) + 限 (limit) = Infinite<br/>未 (not yet) + 定 (decided) = Undecided<br/>非 (non-) + 常 (usual) = Emergency / Unusual |

## 2. Reading Principles: On'yomi vs. Kun'yomi

When reading a compound word, how do you know whether to pronounce it using Chinese-derived **On'yomi (音読み)** or native Japanese **Kun'yomi (訓読み)**?

### The 90% Rule: Pure On'yomi Compounds
If a word consists of two or more bare kanji (without hiragana okurigana sticking out), it is pronounced using **On'yomi** in the vast majority of cases:
- 先生 (*sen-sei*), 会社 (*kai-sha*), 経済 (*kei-zai*), 勉強 (*ben-kyō*).

### The Pure Kun'yomi Rule: Native Japanese Compounds
Compounds describing concrete everyday physical objects, body parts, or compound verbs typically use **Kun'yomi**:
- 手紙 (*te-gami* — hand + paper = letter), 朝日 (*asa-hi* — morning sun), 買物 (*kai-mono* — shopping), 花火 (*hana-bi* — fireworks).

## 3. Hybrid Readings: Jūbako-yomi & Yutō-yomi

Japanese features two celebrated classes of hybrid compound readings where On'yomi and Kun'yomi mix within the same word.

```
重箱読み (Jūbako-yomi) ──► [ 音読み (On) ] ＋ [ 訓読み (Kun) ]
湯桶読み (Yutō-yomi)   ──► [ 訓読み (Kun) ] ＋ [ 音読み (On) ]
```

### A. 重箱読み (Jūbako-yomi: On'yomi + Kun'yomi)
Named after a tiered food box (**重箱 — *jū-bako***: *jū* is On, *bako/hako* is Kun).

| Compound | Reading | Structural Pairing | Meaning |
| :--- | :--- | :--- | :--- |
| **毎朝** | *mai-asa* | 毎 (*mai*: On) + 朝 (*asa*: Kun) | Every morning |
| **番組** | *ban-gumi* | 番 (*ban*: On) + 組 (*kumi*: Kun) | TV program / show |
| **場所** | *ba-sho* | 場 (*ba*: Kun) + 所 (*sho*: On) ➔ *wait: this is Yutō!* | Place / Location |
| **本箱** | *hon-bako* | 本 (*hon*: On) + 箱 (*hako*: Kun) | Bookcase |
| **役場** | *yaku-ba* | 役 (*yaku*: On) + 場 (*ba*: Kun) | Town hall / local office |
| **台所** | *dai-dokoro* | 台 (*dai*: On) + 所 (*tokoro*: Kun) | Kitchen |

### B. 湯桶読み (Yutō-yomi: Kun'yomi + On'yomi)
Named after a wooden hot-water pitcher (**湯桶 — *yu-tō***: *yu* is Kun, *tō* is On).

| Compound | Reading | Structural Pairing | Meaning |
| :--- | :--- | :--- | :--- |
| **手帳** | *te-chō* | 手 (*te*: Kun) + 帳 (*chō*: On) | Pocket notebook / planner |
| **夕刊** | *yū-kan* | 夕 (*yū*: Kun) + 刊 (*kan*: On) | Evening newspaper edition |
| **荷物** | *ni-motsu* | 荷 (*ni*: Kun) + 物 (*motsu*: On) | Luggage / baggage |
| **雨具** | *ama-gu* | 雨 (*ama*: Kun) + 具 (*gu*: On) | Rain gear |
| **消印** | *keshi-in* | 消 (*keshi*: Kun) + 印 (*in*: On) | Postmark stamp |
| **場所** | *ba-sho* | 場 (*ba*: Kun) + 所 (*sho*: On) | Place / location |

## 4. Contextual Disambiguation: One Word, Multiple Readings

Certain kanji compounds shift their pronunciation and meaning depending on context, register, or syntactic position:

| Compound | Reading 1 & Meaning | Reading 2 & Meaning | Contextual Difference |
| :--- | :--- | :--- | :--- |
| **市場** | **いちば (*ichiba*)**<br/>Physical local fish or produce market | **しじょう (*shijō*)**<br/>Abstract economic or financial stock market | *築地魚市場* (Tsukiji fish market: *ichiba*) vs. *株式市場* (Stock market: *shijō*). |
| **上手** | **じょうず (*jōzu*)**<br/>Skillful / Good at | **うわて (*uwate*)**<br/>Upper hand / Outsmarting someone | *日本語が上手* (Good at Japanese) vs. *相手の方が一枚上手だ* (The opponent has the upper hand). |
| **大事** | **だいじ (*daiji*)**<br/>Important / Precious | **たいじ (*taiji*)**<br/>Major event / Serious disaster | *お体を大事に* (Take care of your health) vs. *大事に至る前に* (Before a catastrophe occurs). |
| **色紙** | **しきし (*shikishi*)**<br/>Square card for autographs/poetry | **いろがみ (*irogami*)**<br/>Colored origami craft paper | *有名人に色紙をもらう* (Autograph board) vs. *色紙を折る* (Folding craft paper). |
| **風車** | **ふうしゃ (*fūsha*)**<br/>Large industrial wind turbine | **かざぐるま (*kazaguruma*)**<br/>Children's handheld toy pinwheel | *風力発電の風車* (Wind turbine) vs. *風車を息で回す* (Blowing on a toy pinwheel). |
| **行事 / 行動 / 行方** | **ぎょうじ (*gyōji*)**: Event<br/>**こうどう (*kōdō*)**: Behavior | **ゆくえ (*yukue*)**: Whereabouts | Historical phonetic sound shift based on semantic category. |

## 5. Inferring Unknown Compounds in Reading Passages

When you encounter an unfamiliar 2-kanji or 4-kanji compound on the JLPT Reading section:

```
Step 1: Isolate Radicals (部首)
        ──► Look at the semantic radical (left side or top).
        ──► e.g. 氵(water), 扌(hand/action), 言 (speech), 貝 (money), 忄(emotion).

Step 2: Identify Structural Jukugo Type
        ──► Is it Verb + Object (登山 type)?
        ──► Is it Negation (未定 type)?
        ──► Is it Synonym reinforcement (援助 type)?

Step 3: Analyze Syntactic Slot in the Sentence
        ──► Is it followed by を (Direct Object)?
        ──► Is it followed by する (Verb action)?
        ──► Is it followed by な (Adjectival modifier)?

Step 4: Synthesize Contextual Logic
        ──► Read the preceding sentence and following sentence.
        ──► Substitute your deduced concept to confirm whether the argument holds.
```

### Real Exam Example:
If you encounter **「捏造 (*netsuzō*)」** and don't know the word:
1. Upper kanji has **扌 (hand)**: manipulation, making something.
2. Lower kanji is **造 (create / manufacture)**.
3. Sentence: *「論文のデータを**捏造**した疑いがある。」*
4. Deduction: "Hand-manipulated / fabricated" data in a research paper ➔ **Fabrication / Falsification**!
