# Jukugo (熟語): Structural Typology, Prefixes & Suffixes

At the intermediate and advanced levels (**JLPT N3–N1**), vocabulary acquisition transitions from memorizing individual characters to parsing **Jukugo (熟語 — Multi-Kanji Compounds)**.

By understanding the **5 structural relationships** of compound formation and mastering high-yield **prefixes (接頭辞)** and **suffixes (接尾辞)**, learners can immediately decipher the meaning and grammatical class of thousands of unfamiliar compound words on sight.

---

## 1. The 5 Structural Relationships of 2-Kanji Compounds

Standard Japanese grammatical pedagogy classifies two-character compounds into 5 structural patterns:

```
1. 類義語 (Synonyms)        : [Danger]   + [Danger]   ──> 危険 (Danger)
2. 対義語 (Antonyms)        : [Large]    + [Small]    ──> 大小 (Size / Scale)
3. 修飾関係 (Modifier + Noun): [High]     + [Temp]     ──> 高温 (High Temperature)
4. 目的語 (Verb + Object)   : [Read (V)] + [Book (O)] ──> 読書 (Reading Books)
5. 主述関係 (Subject + Pred) : [Earth (S)]+ [Quake (V)]──> 地震 (Earthquake)
```

| Structure Type | Semantic Relationship | Detailed Analysis & Examples |
| :--- | :--- | :--- |
| **1. Synonym Pair (類義語)** | Both characters share identical or near-synonymous meanings to reinforce the core concept. | • **危険** (*ki-ken*): 危 (peril) + 険 (steep/danger) = **Danger**<br>• **増加** (*zō-ka*): 増 (increase) + 加 (add) = **Augmentation**<br>• **寒冷** (*kan-rei*): 寒 (cold) + 冷 (chilly) = **Coldness**<br>• **製造** (*sei-zō*): 製 (manufacture) + 造 (create) = **Production** |
| **2. Antonym Pair (対義語)** | The two characters are opposites, combining to create an abstract continuum, spectrum, or reciprocal action. | • **大小** (*dai-shō*): Big + Small = **Size / Magnitude**<br>• **売買** (*bai-bai*): Sell + Buy = **Trade / Commerce**<br>• **往復** (*ō-fuku*): Go outward + Return = **Round-trip**<br>• **善悪** (*zen-aku*): Good + Evil = **Morality / Ethics**<br>• **損得** (*son-toku*): Loss + Gain = **Pros and cons / Net balance** |
| **3. Modifier + Noun (修飾関係)** | The 1st kanji functions adjectivally or adverbially to describe the 2nd kanji. | • **親友** (*shin-yū*): Intimate + Friend = **Best friend**<br>• **早起き** (*haya-oki*): Early + Rising = **Early riser**<br>• **急行** (*kyū-kō*): Swift + Travel = **Express train**<br>• **美女** (*bi-jo*): Beautiful + Woman = **Beautiful woman** |
| **4. Verb + Object (動詞・目的語)** | The 1st kanji acts as an active transitive verb upon the 2nd kanji (which serves as its object). | • **読書** (*doku-sho*): Read [V] + Book [O] = **Reading literature**<br>• **帰国** (*ki-koku*): Return to [V] + Homeland [O] = **Repatriation**<br>• **登山** (*to-zan*): Ascend [V] + Mountain [O] = **Mountain climbing**<br>• **就職** (*shū-shoku*): Take up [V] + Profession [O] = **Entering career** |
| **5. Subject + Predicate (主述関係)** | The 1st kanji is the grammatical subject; the 2nd kanji is its predicate action or condition. | • **日没** (*nichi-botsu*): Sun [S] + Sinks [V] = **Sunset**<br>• **地震** (*ji-shin*): Earth [S] + Quakes [V] = **Earthquake**<br>• **国立** (*koku-ritsu*): Nation [S] + Establishes [V] = **National/State-run**<br>• **雷鳴** (*rai-mei*): Lightning [S] + Roars [V] = **Peal of thunder** |

## 2. High-Yield Kanji Prefixes (接頭辞 / Settōji) — JLPT N3 to N1

Prefixes attach to the beginning of root words to alter polarity, temporal status, degree, or scope:

| Prefix | Reading | Core Meaning | High-Frequency JLPT Vocabulary |
| :---: | :--- | :--- | :--- |
| **不〜** | フ、ブ (*fu / bu*) | **Negative / Un- / Lack of** (General negation) | **不安** (*fuan* - anxiety), **不便** (*fuben* - inconvenient), **不足** (*fusoku* - shortage), **不可能** (*fukanō*) |
| **無〜** | ム、ブ (*mu / bu*) | **Without / Devoid of / Free** | **無料** (*muryō* - free of charge), **無理** (*muri* - impossible), **無駄** (*muda* - futile), **無責任** (*musekinin*) |
| **非〜** | ヒ (*hi*) | **Non- / Anti-** (Deviating from norm/reality) | **非常** (*hijō* - emergency/unusual), **非公式** (*hikōshiki* - unofficial), **非現実的** (*higenjitsuteki*) |
| **未〜** | ミ (*mi*) | **Not yet / Pending** (State has not transpired) | **未来** (*mirai* - future), **未成年** (*miseinen* - minor), **未解決** (*mikaiketsu* - unresolved) |
| **再〜** | サイ (*sai*) | **Re- / Again / Second iteration** | **再開** (*saikai* - resumption), **再来年** (*sarainen*), **再生** (*saisei* - playback/regeneration), **再開発** |
| **超〜** | チョウ (*chō*) | **Super- / Ultra- / Exceeding** | **超満員** (*chōman'in* - overcrowded), **超高層** (*chōkōsō* - skyscraper), **超音速** (*chōonsoku*) |
| **総〜** | ソウ (*sō*) | **Total / Comprehensive / Aggregate** | **総理大臣** (*sōridaijin* - Prime Minister), **総合** (*sōgō* - composite), **総人口** (*sōjinkō* - total population) |
| **各〜** | カク (*kaku*) | **Each / Every respective** | **各国** (*kakkoku* - every country), **各自** (*kakuji* - each individual), **各地** (*kakuchi* - all regions) |
| **諸〜** | ショ (*sho*) | **Various / Plurality of** | **諸国** (*shokoku* - various nations), **諸問題** (*shomondai* - various issues), **諸事情** (*shojijō*) |
| **最〜** | サイ (*sai*) | **Most / Utmost (Superlative)** | **最高** (*saikō* - supreme/highest), **最新** (*saishin* - cutting-edge), **最悪** (*saiaku* - worst) |
| **新〜 / 旧〜**| シン / キュウ | **New / Former (Preceding)** | **新製品** (*shinseihin* - new product), **旧姓** (*kyūsei* - maiden name), **旧市街** (*kyūshigai* - old town) |

## 3. High-Yield Kanji Suffixes (接尾辞 / Setsubiji) — JLPT N3 to N1

Suffixes attach to the end of a noun or stem to change its grammatical category (e.g., creating abstract nouns, professions, rates, or adjectives):

| Suffix | Reading | Functional Role | High-Frequency JLPT Vocabulary |
| :---: | :--- | :--- | :--- |
| **〜化** | カ (*-ka*) | **-ization / Transformation** (Turns noun into dynamic change) | **国際化** (*kokusaika* - globalization), **温暖化** (*ondanka* - global warming), **映画化** (*eigaka* - film adaptation) |
| **〜性** | セイ (*-sei*) | **-ity / Nature / Characteristic** (Abstract quality) | **可能性** (*kanōsei* - potential/probability), **安全性** (*anzensei* - safety factor), **必要性** (*hitsuyōsei*) |
| **〜的** | テキ (*-teki*) | **-ic / -al** (Transforms noun into a な-adjective) | **具体的** (*gutaiteki* - concrete/specific), **積極的** (*sekkyokuteki* - proactive), **経済的** (*keizaiteki*) |
| **〜者** | シャ (*-sha*) | **Person possessing a role / Practitioner** | **研究者** (*kenkyūsha* - researcher), **被害者** (*higaisha* - victim), **担当者** (*tantōsha* - person in charge) |
| **〜家** | カ (*-ka*) | **Specialist / Professional / Devotee** | **政治家** (*seijika* - politician), **芸術家** (*geijutsuka* - artist), **専門家** (*senmonka* - expert) |
| **〜費 / 〜料 / 〜代** | ヒ / リョウ / ダイ | **Monetary fee / Cost / Expense** | **交通費** (*kōtsūhi* - transit expenses), **授業料** (*jugyōryō* - tuition), **電気代** (*denkidai* - electricity bill) |
| **〜率** | リツ (*-ritsu*) | **Ratio / Percentage index** | **確率** (*kakuritsu* - mathematical probability), **合格率** (*gōkakuritsu* - pass rate), **失業率** (*shitsugyōritsu*) |
| **〜感** | カン (*-kan*) | **Subjective feeling / Impression** | **安心感** (*anshinkan* - feeling of security), **責任感** (*sekininkan* - sense of responsibility), **違和感** |
| **〜観** | カン (*-kan*) | **Philosophical outlook / Viewpoint** | **世界観** (*sekaikan* - worldview), **人生観** (*jinseikan* - philosophy of life), **価値観** (*kachikan* - values) |
| **〜風** | フウ (*-fū*) | **Style / Aesthetic manner** | **和風** (*wafū* - Japanese-style), **洋風** (*yōfū* - Western-style), **現代風** (*gendaifū* - modern-style) |
| **〜中** | チュウ、ジュウ | **In progress / Across the entire span** | **営業中** (*eigyōchū* - open for business), **一年中** (*ichinenjū* - all year round), **使用中** (*shiyōchū*) |

## 4. Anchor-Kanji Compound Networks

Learning compounds branching out from a single high-frequency anchor kanji accelerates vocabulary growth:

```
           ┌──> 出発 (shuppatsu - departure)
           ├──> 発表 (happyō - presentation)
  [発] ────┼──> 発見 (hakken - discovery)
           ├──> 発達 (hattatsu - development)
           └──> 発明 (hatsumei - invention)

           ┌──> 経済 (keizai - economy)
           ├──> 経営 (keiei - management)
  [経] ────┼──> 経験 (keiken - personal experience)
           ├──> 経過 (keika - progress / passage of time)
           └──> 経歴 (keireki - personal career history)
```
