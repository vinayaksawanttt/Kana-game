# JLPT N5 Survival Sheet: The One-Page Master Summary (N5直前対策シート)

This high-density survival reference card consolidates the complete foundational grammar, conjugations, particles, question words, and essential patterns required to pass the **JLPT N5**. Keep this card open for fast lookup during practice exams and revision.

---

## 1. The Core Sentence Skeleton (文の基本構造)

```
[Topic] は [Time] に [Location] で [Object] を [Verb]。
私は     毎朝     学校で        日本語を   勉強します。
(I study Japanese at school every morning.)
```

### The Copula Grid: "To Be" (〜です)

| Tense / Politeness | Affirmative | Negative |
| :--- | :--- | :--- |
| **Present / Future (Polite)** | **〜です** (*desu*) | **〜ではありません / 〜じゃありません** |
| **Past (Polite)** | **〜でした** (*deshita*) | **〜ではありませんでした** |
| **Present (Casual / Plain)** | **〜だ** (*da*) | **〜じゃない** (*ja nai*) |
| **Past (Casual / Plain)** | **〜だった** (*datta*) | **〜じゃなかった** (*ja nakatta*) |

## 2. The 9 Essential Particles Cheat Sheet (助詞早見表)

| Particle | Primary Function | Gold-Standard Example |
| :---: | :--- | :--- |
| **は** (*wa*) | **Topic Marker**: Highlights what we are talking about ("As for X..."). | 私は学生です。 (*Watashi wa gakusei desu.*) |
| **が** (*ga*) | **Subject Marker**: Marks who/what performs action; introduces new info; marks targets of 好き, 上手, わかる, あります/います. | 猫がいます。 / 日本語が分かります。 |
| **を** (*o*) | **Direct Object**: The item receiving physical action. | 本**を**読みます。 / パン**を**食べます。 |
| **に** (*ni*) | **Target / Exact Time / Destination / Existence Location**: Specific clock time, recipient of action, goal of movement. | 7時**に**起きます。 / 東京**に**行きます。 / 机の上**に**本がある。 |
| **で** (*de*) | **Location of Action / By Means of / Tool**: Where an event happens, vehicle, language. | 図書館**で**勉強する。 / 電車**で**行く。 / 箸**で**食べる。 |
| **へ** (*e*) | **Direction of Motion**: Toward a destination (pronounced *e*). | 日本**へ**ようこそ。 / 病院**へ**向かう。 |
| **と** (*to*) | **Exhaustive "And" / "With"**: Connects nouns completely; accompanies someone. | パン**と**卵。 / 友だち**と**話す。 |
| **も** (*mo*) | **"Also / Too"**: Replaces は, が, or を to mean "also". | 私**も**行きます。 (I will go too.) |
| **の** (*no*) | **Possession / Modifier**: "Of", "'s", connecting two nouns. | 私**の**傘。 / 日本語**の**先生。 |

## 3. Verb Conjugation Master Rules (動詞の活用ルール)

Japanese has 3 verb groups:
1. **Group 1 (五段 — *Godan*)**: Ends in *-u* (e.g. 行く, 飲む, 待つ, 話す).
2. **Group 2 (一段 — *Ichidan*)**: Ends in *-eru* or *-iru* with stem preceding (e.g. 食べる, 見る).
3. **Group 3 (不規則 — *Irregular*)**: Only two verbs: **する (*suru*)** and **来る (*kuru*)**.

### A. The Golden "Te-Form" (て形) Conversion Matrix

```
Group 1 Verbs (五段):
• う, つ, る ──► って   (買う ➔ 買って, 待つ ➔ まって, 帰る ➔ かえって)
• む, ぶ, ぬ ──► んで   (飲む ➔ のんで, 遊ぶ ➔ あそんで, 死ぬ ➔ しんで)
• く        ──► いて   (書く ➔ かいて)   ⚠️ Exception: 行く ➔ 行って
• ぐ        ──► いで   (泳ぐ ➔ およいで)
• す        ──► して   (話す ➔ はなして)

Group 2 Verbs (一段): Drop る, add て (食べる ➔ たべて, 見る ➔ みて)
Group 3 Verbs: する ➔ して  |  来る (くる) ➔ きて
```

### B. High-Frequency Verb Forms Quick Table

| Base Verb | Group | ます (Polite) | ない (Negative) | た (Past) | て形 (Te-Form) | たい (Desire) |
| :--- | :---: | :--- | :--- | :--- | :--- | :--- |
| **書く** (write) | G1 | 書きます | 書かない | 書いた | 書いて | 書きたい |
| **飲む** (drink) | G1 | 飲みます | 飲まない | 飲んだ | 飲んで | 飲みたい |
| **話す** (speak) | G1 | 話します | 話さない | 話した | 話して | 話したい |
| **食べる** (eat) | G2 | 食べます | 食べない | 食べた | 食べて | 食べたい |
| **見る** (see) | G2 | 見ます | 見ない | 見た | 見て | 見たい |
| **する** (do) | G3 | します | しない | した | して | したい |
| **来る** (come) | G3 | 来ます (*kimasu*) | 来ない (*konai*) | 来た (*kita*) | 来て (*kite*) | 来たい (*kitai*) |

## 4. Adjective Conjugation Matrix (形容詞の活用)

### い-Adjectives (e.g., 高い — *takai*) vs な-Adjectives (e.g., 静か — *shizuka*)

| Form | い-Adjective (高い) | な-Adjective (静か) |
| :--- | :--- | :--- |
| **Present Affirmative** | 高いです (*takai desu*) | 静かです (*shizuka desu*) |
| **Present Negative** | 高**くないです** (*takaku nai desu*) | 静か**じゃないです** (*shizuka ja nai desu*) |
| **Past Affirmative** | 高**かったです** (*takakatta desu*) | 静か**でした** (*shizuka deshita*) |
| **Past Negative** | 高**くなかったです** (*takaku nakatta desu*) | 静か**じゃなかったです** (*shizuka ja nakatta desu*) |
| **Connecting Form (And...)** | 高**くて**、おいしい | 静か**で**、きれい |
| **Noun Modifier** | 高い本 (*takai hon*) | 静か**な**町 (*shizuka na machi*) |

> [!WARNING]
> Irregular Adjective **いい (*good*)**:
> - Present Negative: **よくない** (NOT *ikunai*)
> - Past: **よかった** (NOT *ikatta*)
> - Past Negative: **よくなかった**

## 5. Must-Know N5 Sentence Formulas

1. **〜てください** (*...te kudasai*) — Please do: ここに書いてください。
2. **〜てもいいですか** (*...te mo ii desu ka*) — May I do?: 写真を撮ってもいいですか。
3. **〜てはいけません** (*...te wa ikemasen*) — You must not: ここでタバコを吸ってはいけません。
4. **〜ている** (*...te iru*) — Continuous action / ongoing state: 今、勉強しています。 / 結婚しています。
5. **〜たいです** (*...tai desu*) — I want to do: 日本へ行きたいです。
6. **〜に行く** (*stem + ni iku*) — Go in order to do: 映画を見に行きます。
7. **〜ことがある** (*ta-form + koto ga aru*) — Have past experience: 富士山に登ったことがあります。
8. **〜から** (*...kara*) — Because / reason: 暑いですから、窓を開けます。
9. **〜まえに** (*dict + mae ni*) — Before doing: 寝る前に、本を読みます。
10. **〜あとで** (*ta-form + ato de*) — After doing: ご飯を食べた後で、散歩します。

## 6. Question Words (疑問詞)

| Japanese | Romaji | Meaning | Example Question |
| :--- | :--- | :--- | :--- |
| **何** | *nani / nan* | What? | これは何ですか。 (*Kore wa nan desu ka.*) |
| **誰 / どなた** | *dare / donata* | Who? / Who? (polite) | あの人は誰ですか。 (*Ano hito wa dare desu ka.*) |
| **どこ** | *doko* | Where? | お手洗いはどこですか。 (*O-tearai wa doko desu ka.*) |
| **いつ** | *itsu* | When? | 誕生日はいつですか。 (*Tanjōbi wa itsu desu ka.*) |
| **どうして / なぜ** | *dōshite / naze* | Why? | どうして遅れましたか。 (*Dōshite okuremashita ka.*) |
| **どの + Noun** | *dono + Noun* | Which [Noun]? | どの傘があなたのですか。 (*Dono kasa ga...*) |
| **どれ** | *dore* | Which one? | あなたの靴はどれですか。 (*Dore desu ka.*) |
| **どう / いかが** | *dō / ikaga* | How? / How? (polite) | 日本の生活はどうですか。 (*Dō desu ka.*) |
| **いくら** | *ikura* | How much (price)? | この時計はいくらですか。 (*Ikura desu ka.*) |
| **いくつ** | *ikutsu* | How many? / How old? | りんごをいくつ買いましたか。 (*Ikutsu...*) |
