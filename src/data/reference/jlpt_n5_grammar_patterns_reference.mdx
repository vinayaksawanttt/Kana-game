# JLPT N5 Grammar Patterns: Master Reference Sheet

This reference organizes all essential **JLPT N5 grammar patterns** into clear functional groups. Each pattern includes its exact structural connection formula, English meaning, and an authentic example sentence.

---

## 1. Verbal Aspect & Daily Actions (て-Form Patterns)

| Pattern | Connection Formula | Meaning | Example Sentence |
| :--- | :--- | :--- | :--- |
| **〜てください** | Verb [て-form] + ください | *Please do [action]* | ここに名前を書いて**ください**。<br/>(*Please write your name here.*) |
| **〜ています** | Verb [て-form] + います | *Is currently doing (progressive)*<br/>*Is in a state of (resultative)* | 今、日本語を勉強し**ています**。<br/>(*I am studying Japanese right now.*)<br/>東京に住ん**でいます**。<br/>(*I am living in Tokyo.*) |
| **〜てもいいです** | Verb [て-form] + もいいです | *May I...? / It is okay to...* | ここで写真を撮っ**てもいいですか**。<br/>(*May I take a photo here?*) |
| **〜てはいけません** | Verb [て-form] + はいけません | *You must not do [prohibition]* | ここでタバコを吸っ**てはいけません**。<br/>(*You must not smoke here.*) |
| **〜てから** | Verb [て-form] + から | *After doing [A], do [B]* | 手を洗っ**てから**、ご飯を食べます。<br/>(*After washing hands, I eat.*) |

| **〜なければなりません** | Verb [ない-form drop い] + ければなりません | *Must do [obligation / necessity]* | 薬を飲ま**なければなりません**。<br/>(*I must take medicine.*) |
| **〜なくてもいいです** | Verb [ない-form drop い] + くてもいいです | *Do not need to / It is okay not to* | 明日、来**なくてもいいです**。<br/>(*You do not need to come tomorrow.*) |

## 3. Past Experience & Listing Actions (た-Form Patterns)

| Pattern | Connection Formula | Meaning | Example Sentence |
| :--- | :--- | :--- | :--- |
| **〜たことがある** | Verb [た-form] + ことがある | *Have had the experience of doing* | 日本へ行っ**たことがあります**。<br/>(*I have been to Japan before.*) |
| **〜たり〜たりする** | Verb 1 [た-form] + り + Verb 2 [た-form] + りする | *Do things like A and B (non-exhaustive)* | 日曜日は買い物をし**たり**、映画を見**たりしました**。<br/>(*On Sunday I did things like shopping and watching movies.*) |
| **〜たあとで** | Verb [た-form] + あとで / Noun + のあとで | *After doing [action]* | 映画を見**たあとで**、カフェに行きました。<br/>(*After watching the movie, we went to a cafe.*) |

## 6. Comparison & Degree

| Pattern | Connection Formula | Meaning | Example Sentence |
| :--- | :--- | :--- | :--- |
| **A は B より [Adj]** | Noun A + は + Noun B + より + Adj | *A is more [Adj] than B* | 電車はバス**より速い**です。<br/>(*The train is faster than the bus.*) |
| **A と B と どちらが [Adj]** | Noun A + と + Noun B + と + どちらが + Adj | *Between A and B, which is more [Adj]?* | コーヒーとお茶と**どちらが好きですか**。<br/>(*Which do you prefer, coffee or tea?*) |
| **〜の中で [A] が 一番 [Adj]** | Category + の中で + Noun + が一番 + Adj | *Among [Category], [A] is the most [Adj]* | 季節の中で**春が一番好き**です。<br/>(*Among all seasons, I like spring the most.*) |

## 8. Chronological Sequence: 前に vs. あとで

```
Before doing action B:   [Verb Dictionary Form] + 前に (まえに)
After doing action B:    [Verb た-form] + あとで
```

- 寝る**前に**、歯を磨きます。  
  *Neru mae ni, ha o migakimasu.*  
  (Before going to bed, I brush my teeth.)
- ご飯を食べた**あとで**、薬を飲みます。  
  *Gohan o tabeta ato de, kusuri o nomimasu.*  
  (After eating the meal, I take the medicine.)
