# Transitive and Intransitive Verbs

Many Japanese verbs come in pairs that describe a similar event from different angles:

- A **transitive verb** describes someone doing something to an object.
- An **intransitive verb** describes something happening or being in a particular state, without stating who caused it.

These are different verbs, not merely two forms of one verb. Learn each verb with its particles.

## 1. The basic sentence patterns

| Type | Typical pattern | Example |
| :--- | :--- | :--- |
| Transitive | Person は object を transitive verb | 私がドアを開けました。 |
| Intransitive | Thing が intransitive verb | ドアが開きました。 |

> 私が窓を閉めました。  
> I closed the window.
>
> 窓が閉まりました。  
> The window closed.

In the first sentence, the speaker states who performed the action. In the second, the focus is on the window's change of state; the cause may be unknown or unimportant.

## 2. Common pairs

| Transitive: object を | Intransitive: subject が | Meaning |
| :--- | :--- | :--- |
| ドアを開ける | ドアが開く | open |
| 窓を閉める | 窓が閉まる | close |
| 電気をつける | 電気がつく | turn on |
| 電気を消す | 電気が消える | turn off; go out |
| 車を止める | 車が止まる | stop |
| いすを並べる | いすが並ぶ | line up |
| 荷物を入れる | 荷物が入る | put in; enter/be inside |
| 子どもを起こす | 子どもが起きる | wake someone; wake up |
| コップを落とす | コップが落ちる | drop; fall |
| コップを割る | コップが割れる | break; be broken |
| 機械を壊す | 機械が壊れる | break; break down |
| お湯を沸かす | お湯が沸く | boil; make water boil |
| 予定を変える | 予定が変わる | change |
| 人を集める | 人が集まる | gather |

| 名前を決める | 名前が決まる | decide; be decided |
| 問題を解く | 問題が解ける | solve; be solvable / get solved |

## 3. Choosing between を and が

With the transitive verb **開ける**, the door is the direct object and usually takes **を**:

> 店員がドアを開けました。  
> The staff member opened the door.

With the intransitive verb **開く**, the door is the thing that changes and usually takes **が**:

> ドアが開きました。  
> The door opened.

The person or force causing an intransitive event can be included with **で** or another appropriate phrase, but the event still uses the intransitive verb: 強い風でドアが開いた (The door opened in the strong wind).

## 4. Patterns are helpful, but not absolute

Some pairs share recognizable shapes, such as **～ける / ～く** (開ける / 開く), **～す / ～る** (落とす / 落ちる), or **～める / ～まる** (始める / 始まる). These patterns can help recall vocabulary, but they do not let you reliably invent the missing partner. Some verbs have no everyday counterpart, and pair meanings are not always perfectly symmetrical.

Check a dictionary for each verb's meaning, transitivity, and particle pattern. For example, **ドアが開けられた** may mean “the door was opened” (passive), while **ドアが開いた** means “the door opened.”

## 5. A practical way to study pairs

Learn a short sentence with each verb rather than memorizing translations alone:

- 母が窓を開けた。 (My mother opened the window.)
- 窓が開いた。 (The window opened.)
- 私が窓を開けた。 (I opened the window.)
- 窓が開いている。 (The window is open.)

This also helps distinguish an event (**開いた**, opened) from its resulting state (**開いている**, is open).
