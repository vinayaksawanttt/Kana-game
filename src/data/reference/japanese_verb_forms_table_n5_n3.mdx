# Japanese Verb Forms: Conjugation Table

This reference compares the main forms of **書く** (Group 1, write), **食べる** (Group 2, eat), **する** (do), and **来る** (come). Each form has different meanings and uses; the table shows how to build it, not every nuance of its use.

## Form-by-form reference

| Form | Group 1: 書く | Group 2: 食べる | する | 来る |
| :--- | :--- | :--- | :--- | :--- |
| Dictionary | 書く | 食べる | する | 来る (くる) |
| Polite non-past (ます) | 書きます | 食べます | します | 来ます (きます) |
| て-form | 書いて | 食べて | して | 来て (きて) |
| Plain negative (ない) | 書かない | 食べない | しない | 来ない (こない) |
| Plain past (た) | 書いた | 食べた | した | 来た (きた) |
| Conditional (ば) | 書けば | 食べれば | すれば | 来れば (くれば) |
| Potential | 書ける | 食べられる | できる | 来られる (こられる) |
| Passive | 書かれる | 食べられる | される | 来られる (こられる) |
| Causative | 書かせる | 食べさせる | させる | 来させる (こさせる) |
| Imperative | 書け | 食べろ / 食べよ | しろ / せよ | 来い (こい) |
| Volitional | 書こう | 食べよう | しよう | 来よう (こよう) |

## How to build each form

### Polite non-past: ます

- **Group 1:** Change the final kana to its い-row equivalent, then add ます: 書く → 書きます; 話す → 話します.
- **Group 2:** Remove る and add ます: 食べる → 食べます.
- **Irregular:** する → します; 来る → 来ます (きます).

The ます form can describe present habits and future actions. Use context or a time expression to tell which: 毎日、本を読みます (I read every day); 明日、読みます (I will read tomorrow).

### て-form and plain past: て / た

Group 1 endings follow the sound-change patterns in the [て-form rules guide](./japanese_te_form_conjugation_rules_n5.mdx). The た-form uses the same pattern with **た/だ** in place of **て/で**:

- 書く → 書いて → 書いた
- 飲む → 飲んで → 飲んだ
- 話す → 話して → 話した

Group 2: 食べる → 食べて / 食べた. Irregular: する → して / した; 来る → 来て (きて) / 来た (きた).

### Plain negative: ない

- **Group 1:** Change the final kana to its あ-row equivalent, then add ない. For final う, use わ: 書く → 書かない; 買う → 買わない.
- **Group 2:** Remove る and add ない: 食べる → 食べない.
- **Irregular:** する → しない; 来る → 来ない (こない).

### Conditional: ば

- **Group 1:** Change the final kana to its え-row equivalent and add ば: 書く → 書けば; 飲む → 飲めば.
- **Group 2:** Remove る and add れば: 食べる → 食べれば.
- **Irregular:** する → すれば; 来る → 来れば (くれば).

The ば conditional often means “if” or “when, provided that”: 時間があれば、行きます (If I have time, I'll go).

### Potential: ability or possibility

- **Group 1:** Change the final kana to its え-row equivalent and add る: 書く → 書ける.
- **Group 2:** Remove る and add られる: 食べる → 食べられる.
- **Irregular:** する → できる; 来る → 来られる (こられる).

In casual speech, 食べられる may be shortened to 食べれる. The full form **食べられる** is standard in careful writing and is preferable in formal contexts.

### Passive: an action received or experienced

- **Group 1:** Change the final kana to its あ-row equivalent and add れる: 書く → 書かれる; 買う → 買われる.
- **Group 2:** Remove る and add られる: 食べる → 食べられる.
- **Irregular:** する → される; 来る → 来られる (こられる).

Group 2 potential and passive forms look identical; the sentence context identifies the meaning.

### Causative: make or let someone do something

- **Group 1:** Change the final kana to its あ-row equivalent and add せる: 書く → 書かせる; 買う → 買わせる.
- **Group 2:** Remove る and add させる: 食べる → 食べさせる.
- **Irregular:** する → させる; 来る → 来させる (こさせる).

### Imperative and volitional

Imperatives are direct commands and can sound abrupt. Use them with care; in ordinary requests, ～てください or ～てもらえますか is usually more appropriate.

- **Group 1 imperative:** final kana → え-row: 書く → 書け.
- **Group 2 imperative:** remove る + ろ (casual) or よ (literary/formal command): 食べろ / 食べよ.
- **Irregular imperative:** しろ / せよ; 来い (こい).
- **Group 1 volitional:** final kana → お-row + う: 書く → 書こう.
- **Group 2 volitional:** remove る + よう: 食べる → 食べよう.
- **Irregular volitional:** しよう; 来よう (こよう).

Volitional forms can express “let's,” an intention, or a proposed action: 一緒に食べよう (Let's eat together).

## Reading the forms in sentences

| Form | Example | Meaning |
| :--- | :--- | :--- |
| 書いて | 名前を書いてください。 | Please write your name. |
| 書かなかった | 何も書かなかった。 | I didn't write anything. |
| 書けば | 書けば、覚えやすいです。 | If you write it, it's easier to remember. |
| 書ける | 漢字が少し書けます。 | I can write a little kanji. |
| 書かれる | この本は多くの人に読まれている。 | This book is read by many people. |
| 書かせる | 先生は学生に作文を書かせた。 | The teacher had the students write an essay. |

> **Note:** Japanese verbs do not conjugate for grammatical person or number. 私は書く, 彼は書く, and 私たちは書く use the same dictionary form.
