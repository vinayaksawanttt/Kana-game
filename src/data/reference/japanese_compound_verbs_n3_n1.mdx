# Japanese Compound Verbs

A common Japanese compound verb combines the **ます-stem** of one verb with another verb. The second verb adds a meaning such as beginning, continuing, or suddenly starting an action, and it carries the compound's conjugation.

> 読む → 読みます → 読み + 始める → 読み始める  
> to read → begin reading

Do not attach these endings directly to the dictionary form: **読み始める**, not *読む始める*.

## 1. ～始める: begin doing

Attach **始める** to the ます-stem. It presents the start of an action, often neutrally.

| Base verb | Compound | Meaning |
| :--- | :--- | :--- |
| 読む | 読み始める | begin reading |
| 雨が降る | 雨が降り始める | it begins to rain |
| 働く | 働き始める | begin working |
| 話す | 話し始める | begin speaking |

> 子どもが本を読み始めました。  
> The child started reading a book.

## 2. ～続ける: continue doing

Attach **続ける** to the ます-stem. It emphasizes that the action continues over time:

| Base verb | Compound | Meaning |
| :--- | :--- | :--- |
| 勉強する | 勉強し続ける | continue studying |
| 走る | 走り続ける | keep running |
| 待つ | 待ち続ける | continue waiting |
| 使う | 使い続ける | keep using |

> 彼女は三時間話し続けました。  
> She kept talking for three hours.

～続ける can sound more deliberate or sustained than simply saying that an action happens repeatedly.

## 3. ～出す: start suddenly; break into doing

Attach **出す** to the ます-stem. With many action verbs, it highlights a sudden or unanticipated start:

| Base verb | Compound | Typical nuance |
| :--- | :--- | :--- |
| 泣く | 泣き出す | suddenly start crying |
| 笑う | 笑い出す | burst out laughing |
| 雨が降る | 雨が降り出す | suddenly start raining |
| 走る | 走り出す | start running / run off |

> みんなが急に笑い出しました。  
> Everyone suddenly burst out laughing.

Compare:

- 赤ちゃんが泣き始めた。 — The baby began to cry (a relatively neutral description).
- 赤ちゃんが泣き出した。 — The baby started crying suddenly / broke into tears.

The distinction is one of typical emphasis, not an absolute rule: context can make ～始める and ～出す overlap.

## 4. Conjugate the final verb

The first verb remains in its ます-stem form; conjugate the compound's final verb as needed:

| Compound dictionary form | ます | て-form | ない |
| :--- | :--- | :--- | :--- |
| 読み始める | 読み始めます | 読み始めて | 読み始めない |
| 使い続ける | 使い続けます | 使い続けて | 使い続けない |
| 泣き出す | 泣き出します | 泣き出して | 泣き出さない |

## 5. Watch for lexicalized meanings

Not every verb ending in 始める, 続ける, or 出す is a freely formed compound with a predictable meaning. Some combinations become established vocabulary, and a compound may have a specialized meaning in context. Check an example sentence or dictionary entry when the literal interpretation does not fit.

> **Study tip:** Learn the ます-stem, the compound's meaning, and the aspectual nuance together: 読み始める (begin reading), 読み続ける (continue reading), 読み出す (start reading, often suddenly or unexpectedly).
