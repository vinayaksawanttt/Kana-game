# Japanese IME Typing and Keyboard Shortcuts (日本語入力とタイピング)

To communicate in digital Japanese, you will use an **Input Method Editor (IME)**. The vast majority of Japanese speakers and learners type phonetically using **Romaji Input (ローマ字入力)**, where standard QWERTY Latin keystrokes are automatically converted into Hiragana, Katakana, and Kanji.

Mastering specific phonetic combinations, small kana prefixes, and function hotkeys will dramatically increase your Japanese typing speed and prevent common conversion mistakes.

---

## 1. Core Romaji Input Rules (基本のローマ字入力)

The IME converts syllables into Hiragana as you type. Pressing the **Spacebar** cycles through Kanji conversion candidates, and pressing **Enter** confirms (*kakutei*) your text.

```
Keystrokes:   t  ➔  o  ➔  k  ➔  y  ➔  o  ➔  u
Buffer display:  と   き   ょ   う  (とうきょう)
Press Space:    東京  (Converted to Kanji)
Press Enter:    東京  (Committed to document)
```

## 2. Tricky Phonetic Typing Rules (注意すべき入力ルール)

### A. The Small Tsu (っ / 促音: Sokuon)
There are two ways to produce the small **っ**:
1. **Double the following consonant (Recommended)**:
   - Type `matte` ➔ **まって** (待って)
   - Type `zasshi` ➔ **ざっし** (雑誌)
   - Type `kitte` ➔ **きって** (切手)
   - Type `gakkou` ➔ **がっこう** (学校)
2. **Standalone small tsu**: Type `xtsu` or `ltsu` (the `x` or `l` stands for "little").
   - Useful when typing interjections or words ending in a glottal stop: `あっ` (type `a` + `xtsu`).

---

### B. The Syllable "ん" (撥音: Hatsuon)
Typing the single letter `n` is often ambiguous to the IME because `n` could begin `na`, `ni`, `nu`, `ne`, or `no`.
- **The Rule**: Always type **`nn`** (double n) to guarantee **ん**:
  - Type `kannyou` ➔ **かんよう** (寛容 — tolerance)
  - If you only type `kanyou`, the IME types **か・に・ょ・う** ➔ **かに入**!
- At the end of a word, type `nn` or type `n` followed by `Enter` or `Space`:
  - `nihon` + Enter ➔ **にほん** (日本)

---

### C. Small Combination Kana (ゃ, ゅ, ょ, ぁ, ぃ, etc.)
1. **Natural digraphs**:
   - `kya` (きゃ), `kyu` (きゅ), `kyo` (きょ)
   - `sha` / `sya` (しゃ), `shu` / `syu` (しゅ), `sho` / `syo` (しょ)
   - `cha` / `tya` (ちゃ), `chu` / `tyu` (ちゅ), `cho` / `tyo` (ちょ)
   - `nya` (にゃ), `hya` (ひゃ), `mya` (みゃ), `rya` (りゃ)
   - `ja` / `zya` (じゃ), `ju` / `zyu` (じゅ), `jo` / `zyo` (じょ)
2. **Standalone small vowels**: Prefix with **`x`** or **`l`** ("little"):
   - `xa` ➔ **ぁ**, `xi` ➔ **ぃ**, `xu` ➔ **ぅ**, `xe` ➔ **ぇ**, `xo` ➔ **ぉ**
   - `xya` ➔ **ゃ**, `xyu` ➔ **ゅ**, `xyo` ➔ **ょ**, `xwa` ➔ **ゎ**

### D. Alternative & Archaic Romaji Spellings

| Kana | Primary Keystroke | Working Alternatives | Notes |
| :---: | :---: | :---: | :--- |
| **し** | `shi` | `si` | Nihon-shiki / Kunrei-shiki system |
| **ち** | `chi` | `ti` | Kunrei-shiki system |
| **つ** | `tsu` | `tu` | Kunrei-shiki system |
| **ふ** | `fu` | `hu` | Kunrei-shiki system |
| **じ** | `ji` | `zi` | Hepburn vs Kunrei |
| **ぢ** | `di` | `dji` | Voiced *chi* (e.g. `hanaji` ➔ `hanadi` ➔ 鼻血) |
| **づ** | `du` | `dzu` | Voiced *tsu* (e.g. `tsuzuku` ➔ `tudukeru` ➔ 続ける) |
| **を** | `wo` | — | Particle *o* (always typed as `wo` to avoid getting お) |

### E. Extended Katakana for Foreign Loanwords (外来語)

Modern loanwords require sounds not found in traditional Japanese:

| Katakana | Keystroke | Practical Loanword Example |
| :---: | :---: | :--- |
| **ファ, フィ, フェ, フォ** | `fa`, `fi`, `fe`, `fo` | ファックス (*fakku su* — fax), カフェ (*kafe* — café) |
| **ティ, ディ** | `ti`, `di` | パーティー (*pātī* — party), ディズニー (*dizunī* — Disney) |
| **ウィ, ウェ, ウォ** | `wi`, `we`, `wo` | ウィンドウ (*windō* — window), ウェブ (*webu* — web) |
| **シェ, ジェ, チェ** | `she`, `je`, `che` | シェア (*shea* — share), チェック (*chekku* — check) |
| **ツァ, ツィ, ツェ, ツォ** | `tsa`, `tsi`, `tse`, `tso` | モーツァルト (*mōtsaruto* — Mozart) |
| **ヴァ, ヴィ, ヴ, ヴェ, ヴォ** | `va`, `vi`, `vu`, `ve`, `vo` | ヴァイオリン (*vaiorin* — violin) |

> [!TIP]
> The Katakana long vowel mark (**ー**) is typed using the **Hyphen/Minus key (`-`)** while in Japanese input mode:
> - `ko-hi-` ➔ **コーヒー** (coffee)
> - `su-pa-` ➔ **スーパー** (supermarket)

## 3. IME Conversion Hotkeys (F6 to F10 Shortcuts)

While typing a word (before pressing `Enter` to confirm), Windows and many Linux/Mac IMEs support standard function key conversions:

| Key Shortcut | Function | Transformation Example |
| :---: | :--- | :--- |
| **F6** (or `Ctrl + U`) | Convert buffer to **Full-width Hiragana** (全角ひらがな) | `nihon` ➔ **にほん** |
| **F7** (or `Ctrl + I`) | Convert buffer to **Full-width Katakana** (全角カタカナ) | `nihon` ➔ **ニホン** |
| **F8** (or `Ctrl + O`) | Convert buffer to **Half-width Katakana** (半角ｶﾀｶﾅ) | `nihon` ➔ **ﾆﾎﾝ** |
| **F9** (or `Ctrl + P`) | Convert buffer to **Full-width Romaji Alphabet** | `nihon` ➔ **ｎｉｈｏｎ** |
| **F10** (or `Ctrl + T`) | Convert buffer to **Standard Half-width Romaji** | `nihon` ➔ **nihon** |

```
Workflow Example:
1. You want to type the loanword "Smartphone" in Katakana.
2. Type: sumaho (Buffer shows: すまほ)
3. Press F7 immediately ➔ スマホ
4. Press Enter to confirm!
```

## 4. Japanese Punctuation & Symbol Shortcuts

| Symbol | Name | How to Type | Meaning & Use |
| :---: | :--- | :--- | :--- |
| **、** | 読点 (*tōten*) | Press `,` (comma) | Japanese comma |
| **。** | 句点 (*kuten*) | Press `.` (period) | Japanese period |
| **「 」** | かぎ括弧 (*kagikakko*) | Press `[` and `]` | Japanese quotation marks |
| **『 』** | 二重かぎ括弧 | Type `kakko` + Space | Quotes within quotes, book/movie titles |
| **〜** | 波ダッシュ (*nami dasshu*) | Press `Shift + ~` (tilde) | "From... to...", playful elongation |
| **・** | 中黒 (*nakaguro*) | Press `/` (slash) | Separating foreign names (e.g., スティーブ・ジョブズ) |

### Secret Symbol Typing Tricks
You can convert Japanese words into special typographic symbols by pressing **Space**:
- Type `yajirushi` (矢印) ➔ **→, ←, ↑, ↓, ⇄**
- Type `maru` (丸) ➔ **◯, ◎, ●, ⓪, ①**
- Type `batsu` (罰) ➔ **✕, ✖**
- Type `hoshij` (星) ➔ **★, ☆**
- Type `onaji` (同じ) ➔ **々** (Kanji repetition mark: 人々, 時々)
- Type `yuubin` (郵便) ➔ **〒** (Japanese postal symbol)
- Type `kigou` (記号) ➔ List of dozens of mathematical and typographical glyphs.
