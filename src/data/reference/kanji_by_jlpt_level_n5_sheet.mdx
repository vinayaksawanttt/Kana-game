# JLPT N5 Kanji Complete Reference Sheet (103 Kanji)

This reference sheet covers all **103 foundational kanji** required for the **JLPT N5**, grouped into 6 logical thematic categories:
- **On'yomi (音読み / Sino-Japanese)**: Written in **Katakana**.
- **Kun'yomi (訓読み / Native Japanese)**: Written in **Hiragana** (with okurigana following a dot `・`).
