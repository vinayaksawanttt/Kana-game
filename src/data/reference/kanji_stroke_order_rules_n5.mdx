# Kanji Stroke Order Rules (筆順 - Hitsujun)

Writing kanji with the correct **stroke order (筆順 / *hitsujun*)** is not merely an arbitrary aesthetic exercise—it is the engineering foundation of Japanese typography:
1. **Balance & Proportions**: Characters naturally achieve balanced weight, correct spacing, and proper posture.
2. **Speed & Legibility**: In cursive handwriting (*gyōsho*), strokes naturally flow into one another; incorrect order breaks this calligraphy momentum.
3. **Dictionary & Input Lookups**: Stroke-counting and radical lookup systems depend entirely on knowing which stroke is which.

---

## The 8 Golden Rules of Stroke Order

### Rule 1: Top to Bottom (上から下へ)
Write upper strokes before lower strokes.
- **三** (*san* - three): Top horizontal stroke $\rightarrow$ middle horizontal $\rightarrow$ bottom horizontal.
- **言** (*iu / koto* - word/say): Top dot $\rightarrow$ three horizontal bars $\rightarrow$ bottom mouth radical (**口**).

### Rule 2: Left to Right (左から右へ)
Write left-side components and strokes before right-side ones.
- **川** (*kawa* - river): Left vertical curve $\rightarrow$ middle short stroke $\rightarrow$ right long vertical stroke.
- **休** (*yasumu* - rest): Complete the left radical **亻** (person) before writing **木** (tree) on the right.
- **明** (*akarui* - bright): Complete the left radical **日** (sun) before writing **月** (moon) on the right.

### Rule 3: Horizontal Before Vertical (横から縦へ)
When a horizontal stroke and a vertical stroke intersect, write the **horizontal stroke first**.
- **十** (*jū* - ten): Horizontal bar (一) first $\rightarrow$ vertical piercing line (丨).
- **木** (*ki* - tree): Horizontal bar first $\rightarrow$ center vertical trunk $\rightarrow$ left diagonal sweep $\rightarrow$ right diagonal sweep.

> [!WARNING] Crucial Exception: Bottom "Floor" Horizontal Strokes
> When a horizontal stroke acts as an uncrossed bottom pedestal or base (such as in **土**, **王**, **立**, **上**), write the vertical stroke **before** the final bottom horizontal stroke:
> - **土** (*tsuchi* - ground): Top horizontal $\rightarrow$ vertical stroke $\rightarrow$ bottom baseline horizontal.
> - **王** (*ō* - king): Top horizontal $\rightarrow$ middle horizontal $\rightarrow$ vertical center $\rightarrow$ bottom baseline horizontal.

### Rule 4: Center Before Symmetrical Sides (中から外へ)
When a central vertical stroke is flanked symmetrically by left and right strokes, write the **center stroke first**, then the **left stroke**, then the **right stroke**.
- **小** (*chiisai* - small): Center vertical hook (亅) $\rightarrow$ left dot (ノ) $\rightarrow$ right dot (＼).
- **水** (*mizu* - water): Center vertical hook $\rightarrow$ left corner/sweep $\rightarrow$ right sweeping strokes.

### Rule 5: Outside Before Inside for Enclosures (外から中へ)
When an outer frame surrounds inner components on two or three sides, draw the **outer frame first** before inserting the inside content.
- **同** (*onaji* - same): Outer 3-sided frame (**冂**) first $\rightarrow$ inner **一** $\rightarrow$ inner **口**.
- **風** (*kaze* - wind): Outer sweeping frame (**几**) first $\rightarrow$ inner **虫** (insect) component.
- **月** (*tsuki* - moon): Outer frame first $\rightarrow$ two inner horizontal lines.

### Rule 6: Close the Bottom of a Full Box Last (中を囲んで最後に閉じる)
For full 4-sided box enclosures (such as **口**, **日**, **四**, **国**):
1. Left vertical stroke.
2. Top-and-right corner (**drawn as a single continuous stroke** without lifting the pen!).
3. Draw all inner elements completely.
4. **Seal the bottom horizontal closing stroke last**.
- **日** (*hi* - sun): Left vertical $\rightarrow$ top-right corner $\rightarrow$ middle horizontal $\rightarrow$ bottom closing horizontal.
- **国** (*kuni* - country): Outer left vertical $\rightarrow$ outer top-right corner $\rightarrow$ complete inner **玉** (jewel) $\rightarrow$ outer bottom closing horizontal.

### Rule 7: Left-Sweep Before Right-Sweep (左払いから右払いへ)
When diagonal slanting strokes meet or cross, draw the stroke slanting down-to-the-left (**ノ**) before the stroke slanting down-to-the-right (**＼**).
- **人** (*hito* - person): Left-sweep (ノ) first $\rightarrow$ right-sweep (＼).
- **文** (*bun* - writing/literature): Top dot $\rightarrow$ horizontal bar $\rightarrow$ left-sweep $\rightarrow$ right-sweep.
- **父** (*chichi* - father): Top two diagonal marks $\rightarrow$ long left-sweep $\rightarrow$ long right-sweep.

### Rule 8: Piercing Center Strokes Go Last (貫く線は最後)
When a stroke passes vertically or horizontally all the way through a series of enclosed strokes, draw it **after** the shapes it pierces.
- **中** (*naka* - inside): Complete the outer box (**口**) first $\rightarrow$ draw the vertical piercing stroke through the center last.
- **車** (*kuruma* - car): Top horizontal $\rightarrow$ middle box (**日**) $\rightarrow$ lower horizontal $\rightarrow$ long vertical center piercing stroke last.
- **母** (*haha* - mother): Outer frame $\rightarrow$ two inner dots $\rightarrow$ long horizontal piercing bar last.

## Vital Radical Exceptions: Movement Radicals (辶 & 廴)

Normally, left-hand components are written first (Rule 2). However, the **road/movement radical (辶 - *shinnyō*)** and the **long-stride radical (廴 - *ennyō*)** are the most famous exception in Japanese orthography:
- **Rule**: Write the **inner / upper-right component FIRST**, and write the **辶 / 廴 radical LAST**!

| Kanji | Meaning | Correct Stroke Sequence |
| :--- | :--- | :--- |
| **道** (*michi* - road) | Road / Way | 1st: Complete **首** (neck/head) $\rightarrow$ 2nd: Draw **辶** (*shinnyō*) wrapping underneath last. |
| **近** (*chikai* - near) | Near | 1st: Complete **斤** (axe) $\rightarrow$ 2nd: Draw **辶** (*shinnyō*) last. |
| **遠** (*tōi* - far) | Distant | 1st: Complete **袁** (long robe) $\rightarrow$ 2nd: Draw **辶** (*shinnyō*) last. |
| **週** (*shū* - week) | Week / Cycle | 1st: Complete **周** (circuit) $\rightarrow$ 2nd: Draw **辶** (*shinnyō*) last. |
| **建** (*tateru* - build) | Construct | 1st: Complete **聿** (writing brush) $\rightarrow$ 2nd: Draw **廴** (*ennyō*) last. |

> [!TIP] The Three-Stroke Shinnyō (辶) Breakdown
> In standard modern Japanese Joyo kanji:
> 1. Stroke 1: Top dot.
> 2. Stroke 2: The zigzag lightning stroke (starts horizontal, angles down-left, loops down-right).
> 3. Stroke 3: The sweeping flat bottom tail flowing under the whole character.
