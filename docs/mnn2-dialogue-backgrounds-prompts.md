# Minna no Nihongo III — Dialogue Scene Locations & Background Prompts

This guide maps all **12 lessons (Lessons 1–12)** (`話す・聞く` Dialogues) of **Minna no Nihongo III** to visual background assets under `public/images/books/backgrounds/`.

To avoid redundant asset generation:
* **6 lessons** cleanly reuse existing backgrounds (`apartment-hallway-genkan`, `imc-office-day`, `25-neighborhood-cafe`, `35-electronics-store`, `yamada-living-room-day`).
* **6 new MNN III backgrounds (`72`–`77`)** cover the signature *Minna no Nihongo III* settings (Civic Hall Lobby, Commuter Station Platform, Brazil Air Office, Supermarket Service Counter, Apartment Stairs Entrance, and Nighttime Apartment Corridor).

---

## Global Style Guidelines

> **Base Style Suffix (built into every prompt below):**
> `Japanese anime visual novel background art, clean modern Slice-of-Life aesthetic, Makoto Shinkai / Kyoto Animation inspired lighting, 16:9 wide aspect ratio, no characters, no people, no text, no watermarks, soft atmospheric depth so foreground UI and dialogue bubbles remain easily readable.`
